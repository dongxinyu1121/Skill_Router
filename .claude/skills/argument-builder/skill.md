# 论点推进

本技能专门处理议论文、说理性文章的逻辑链卡壳。当作者知道自己的核心观点，但不知道下一步该论证什么，或者论证链条感觉断了，本技能帮助理清论证结构，找到下一步方向。

## Workflow

### 第一步：提取核心论点

从已写内容中提取：
- **中心论点**：文章最终要说服读者相信什么
- **已有分论点**：已经论证过的支撑观点
- **已用论证方式**：举例 / 数据 / 类比 / 权威引用 / 反驳

如果中心论点不明确，停止推进，要求作者先明确说明。

### 第二步：诊断论证链条的断点

对照标准论证结构，识别缺少哪一环：

```
完整论证链条：
中心论点
  ├── 分论点 A（+论据+推导）
  ├── 分论点 B（+论据+推导）
  ├── 分论点 C（+论据+推导）
  ├── 反驳潜在质疑（可选但重要）
  └── 结论（回扣中心论点）
```

常见断点类型：
- **论点不够**：已有论据，但分论点不足以覆盖主张
- **论据缺失**：有观点但缺乏支撑材料
- **推导缺失**：有论据但没说清楚为什么能得出该论点
- **反驳缺失**：论证显得片面，没有处理反方观点
- **结论缺失**：论证完成但没有收束回中心论点

### 第三步：提出下一步论证方向

针对识别出的断点，给出 2-3 个方向：

每个方向包含：
- **论点内容**：下一步要论证什么
- **建议论证方式**：举例 / 数据 / 类比 / 反驳 / 权威引用
- **论证功能**：这一步在整体论证链中的作用

### 第四步：输出结果

```
【论点推进结果】
中心论点：[提取或确认]
已完成论证：[已有分论点列表]
断点位置：[论证链条在哪里断了]

方向 A：[下一个论点]
　论证方式：[建议方式]
　论证功能：[在链条中的作用]

方向 B：[下一个论点]
　论证方式：[建议方式]
　论证功能：[在链条中的作用]

方向 C：[下一个论点]（可选）
　论证方式：[建议方式]
　论证功能：[在链条中的作用]

推荐：方向 [X]，原因：[一句话]
逻辑提示：[如果已有论证存在逻辑问题，在此指出]
```

## Usage

粘贴已写内容，并注明核心论点（如果文章中不明确）。本技能自动分析论证进展和缺口。

## Examples

### 示例 1：分论点推进

**输入：**
> 中心论点：远程工作对员工和企业都更有利
> 已写内容：论证了"员工效率更高"（引用了两项研究数据）

**输出：**
```
【论点推进结果】
中心论点：远程工作对员工和企业双方都更有利
已完成论证：分论点1—员工效率提升（数据支撑）
断点位置：企业视角的论证尚未展开；反方质疑未处理

方向 A：从企业视角补充分论点（成本节约）
　论证方式：数据——办公室租金、基础设施成本的实际数字
　论证功能：完成"企业受益"这一侧的论证

方向 B：从企业视角补充分论点（人才获取范围扩大）
　论证方式：举例——哪些企业因此获得了原本无法招募的人才
　论证功能：提供"企业受益"的第二个维度，使论证更全面

方向 C：处理反方质疑（协作和团队凝聚力问题）
　论证方式：反驳——承认问题存在，再论证可通过工具/制度解决
　论证功能：增强论证的客观性，防御读者的质疑

推荐：方向 A，原因：当前论证只覆盖了员工侧，论点声称"双方受益"但企业侧完全空白
逻辑提示：无
```

### 示例 2：推导缺失

**输入：**
> 中心论点：大城市的年轻人应该考虑回乡发展
> 已写内容：列举了大城市高房价、高生活成本、竞争激烈的数据

**输出：**
```
【论点推进结果】
中心论点：大城市年轻人应考虑回乡发展
已完成论证：大城市生存压力大（数据）
断点位置：数据只说明了"大城市很难"，没有推导出"因此应该回乡"——中间缺少一步

方向 A：补充推导步骤（回乡的实际机会在增加）
　论证方式：数据+案例——新一线城市政策、产业转移、创业成本对比
　论证功能：连接"大城市难"与"回乡值得考虑"的逻辑桥梁

方向 B：从个人价值实现角度论证
　论证方式：举例——在二三线城市反而获得更快晋升或创业成功的真实案例
　论证功能：提供正向理由，而非只有负向推力

推荐：方向 A，原因：目前论证只有"逃离"的理由，缺乏"去哪"的正向依据，读者会觉得说服力不足
逻辑提示：当前论证只提供了"推力"（大城市太难），没有"拉力"（回乡有什么好），完整的论证需要两者兼顾
```

## Best Practices

- 不替作者写论证内容，只提供方向和论证策略；具体论据由作者自己补充。
- 发现已有逻辑漏洞（如论据不支持论点、循环论证）时，必须在"逻辑提示"中指出，不能绕过。
- 议论方式要与文章已有风格一致：学术文章建议引用数据，公众号文章建议用故事和类比。

## Edge Cases

- **中心论点不明确**：无法推进，直接要求作者用一句话说清楚"你要说服读者相信什么"。
- **已有论证存在根本性错误**：暂停推进方向，优先指出错误并建议使用 `contradiction-resolver`。
- **文章不是议论文**：说明本技能适用场景，并建议使用 `outline-expander`。
