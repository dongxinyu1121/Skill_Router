# 比例平衡

本技能解决文章各部分比例严重失衡的问题。当次要内容占据了太多篇幅，主线反而显得薄弱，或者文章整体头重脚轻/虎头蛇尾，本技能帮助重新分配篇幅，使各部分比例符合文章的重要性权重。

## Workflow

### 第一步：建立各部分的重要性权重

读取全文，将内容分为若干部分，并对每部分的"核心贡献度"评级：

| 等级 | 说明 |
|------|------|
| 核心（C） | 文章主张或情感的直接载体，最关键 |
| 支撑（S） | 为核心服务，解释、举例、论证 |
| 背景（B） | 铺垫、过渡、交代语境，必要但非核心 |
| 冗余（R） | 对文章目的贡献不足，可以删减或删除 |

### 第二步：对比实际篇幅与理想比例

| 文章类型 | 建议比例参考 |
|---------|-----------|
| 议论文 | 背景10-15% / 论证70-75% / 结论10-15% |
| 散文 | 引入15-20% / 展开60-65% / 落脚20-25% |
| 说明文 | 概述10% / 详述70-75% / 总结15% |
| 故事/小说 | 建置20% / 发展与冲突60% / 解决20% |

### 第三步：识别失衡类型

| 失衡类型 | 具体表现 |
|---------|---------|
| 头重脚轻 | 开头/背景部分过长，主体部分薄弱 |
| 虎头蛇尾 | 前半段充实，后半段仓促或缺失 |
| 中间塌陷 | 开头结尾都有，中间核心论述不足 |
| 次要内容反客为主 | 某个支撑性内容篇幅超过核心内容 |

### 第四步：输出结果

```
【比例平衡分析】
文章类型：[判断结果]
建议总篇幅：[如果作者未指定，根据类型给出参考范围]

各部分评估：
　[部分名称]：[实际篇幅] / 重要性等级[C/S/B/R] / [正常/偏多/偏少/缺失]

失衡类型：[识别结果]
主要问题：[最严重的失衡在哪里]

调整建议：
　需要压缩：[哪些部分，压缩到大约多少字]
　需要扩充：[哪些部分，扩充方向是什么]
　建议删除：[哪些冗余内容]

调整后的理想结构：
　[部分1]：约X字（[C/S/B]）
　[部分2]：约X字（[C/S/B]）
　...
```

## Usage

提供全部已写内容或各部分的摘要，以及文章类型和预期总篇幅。

## Examples

### 示例 1：次要内容反客为主

**输入：**
> 文章类型：议论文，论证"读纸质书比读电子书更有价值"
> 结构：引言150字→背景（书的历史和电子书发展）800字→核心论证300字→结尾100字
> 总计1350字

**输出：**
```
【比例平衡分析】
文章类型：议论文
建议总篇幅：1200-1500字（当前字数合适）

各部分评估：
　引言：150字 / 重要性B / 正常
　书的历史和电子书发展背景：800字 / 重要性B / 严重偏多（占59%篇幅，而重要性只是背景级）
　核心论证：300字 / 重要性C / 严重偏少（核心内容只占22%篇幅）
　结尾：100字 / 重要性S / 偏少

失衡类型：次要内容反客为主（背景部分是核心论证的2.7倍）
主要问题：800字的背景把核心论证挤压成了300字，议论文的灵魂——论证——严重不足

调整建议：
　需要压缩：背景部分从800字压缩到150字左右，只保留最关键的一两个背景信息
　需要扩充：核心论证从300字扩充到800-900字，每个分论点需要有充分的论据支撑
　建议删除：书的历史演变的详细描述（与"纸质书vs电子书"的核心论点关联不大）

调整后的理想结构：
　引言：150字（B）
　背景（极简）：150字（B）
　核心论证：800字（C）—— 至少2-3个分论点，每个有论据
　结尾：150字（S）
　合计约1250字
```

### 示例 2：虎头蛇尾

**输入：**
> 文章类型：散文，写一次登山经历
> 结构：出发前准备和心情600字→登山过程中的所见所感200字→到达山顶50字→返程和感悟50字

**输出：**
```
【比例平衡分析】
文章类型：散文
建议总篇幅：800-1200字

各部分评估：
　出发前准备和心情：600字 / 重要性B-S / 偏多（占67%篇幅）
　登山过程所见所感：200字 / 重要性C / 偏少（核心体验只占22%）
　山顶时刻：50字 / 重要性C / 严重偏少（高潮部分几乎缺失）
　返程和感悟：50字 / 重要性C / 严重偏少（落脚点太弱）

失衡类型：虎头蛇尾（铺垫充分但高潮和落脚都仓促）
主要问题：山顶时刻是这篇散文的情感高潮，但只有50字；感悟是落脚点，也只有50字——两个最重要的部分反而最薄弱

调整建议：
　需要压缩：出发前准备从600字压缩到200-250字，只保留最有氛围感的部分
　需要扩充：
　　- 登山过程扩充到300字（感官细节、心理变化、某个令人印象深刻的时刻）
　　- 山顶时刻扩充到200字（这是全篇的情感高点，值得细写）
　　- 感悟扩充到150-200字（不要说教，从一个具体的感受落脚）

调整后的理想结构：
　出发前：200字（B）
　登山过程：300字（C）
　山顶时刻：200字（C）
　感悟落脚：150字（C）
　合计约850字
```

## Best Practices

- 比例建议要结合文章类型，不同类型有不同的合理比例，不能用一个标准套所有文章。
- 压缩建议必须具体说明"删什么"，"写少点"没有操作价值。
- 如果某部分内容质量很好但占比过多，建议作者保存完整版，考虑另立文章详写。

## Edge Cases

- **作者不清楚文章类型**：根据内容判断，并在结果中说明判断依据。
- **文章太短（不足300字）**：无法做有效的比例分析，建议先把全文写到基本完整再来分析。
- **作者坚持某种特殊比例安排**：尊重作者意图，但说明这种安排对读者体验的可能影响。
