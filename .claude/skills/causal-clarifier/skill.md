# 因果关系梳理

本技能解决"知道结论，但推导过程理不清楚"或"因果关系写反了"的逻辑类卡壳。当作者确定A和B之间有关系，但说不清是A导致B还是B导致A，或者推导链条混乱，本技能帮助梳理清楚。

## Workflow

### 第一步：提取作者的因果主张

识别作者想说的因果关系：
- **原因（A）**：是什么
- **结果（B）**：是什么
- **作者的主张**：A导致B，还是B导致A，还是不确定

### 第二步：检验因果方向

用以下三个测试检验因果方向：

**测试1：时间顺序**
A是否在B之前发生？因必须先于果。

**测试2：干预测试**
如果人为增加/减少A，B会对应变化吗？（如果是，说明A确实影响B）

**测试3：排除共因**
有没有第三个因素C同时导致了A和B？（如果有，A和B的"因果关系"可能只是共同结果）

### 第三步：梳理因果链条

如果因果关系确定，帮助作者把链条拆解清楚：

```
简单因果：A → B
多步因果：A → 中间机制1 → 中间机制2 → B
多因一果：A1 + A2 + A3 → B
一因多果：A → B1 + B2 + B3
```

### 第四步：输出结果

```
【因果关系梳理】
作者的主张：[A导致B的描述]

因果检验：
　时间顺序：[A是否先于B发生]
　干预测试：[改变A是否会改变B]
　排除共因：[有无第三因素同时影响A和B]

诊断：
　因果方向：[A→B / B→A / 双向 / 相关但无直接因果]
　因果类型：[简单/多步/多因一果/一因多果]

梳理后的因果链条：
[A] → [中间机制（如有）] → [B]

写作建议：[如何在文章中清晰表达这个因果关系]
```

## Usage

提供你想表达的因果关系（A和B是什么），以及已写的相关段落（如果有）。

## Examples

### 示例 1：因果方向不确定

**输入：**
> 我想写"阅读习惯和学业成绩的关系"
> 不确定是"读书多导致成绩好"还是"成绩好的人喜欢读书"

**输出：**
```
【因果关系梳理】
作者的主张：阅读习惯与学业成绩之间有正相关关系，但因果方向不确定

因果检验：
　时间顺序：阅读习惯可以在成绩形成之前建立（如小时候就培养阅读），所以A→B在时间上可行
　干预测试：研究显示，介入阅读训练计划后，学生成绩有可测量的提升——支持A影响B
　排除共因：家庭教育环境可能同时促进阅读习惯和学业成绩——这是需要考虑的第三因素

诊断：
　因果方向：主要是A→B（阅读促进成绩），但也存在正向循环（成绩好增加阅读兴趣）
　因果类型：多步因果（阅读→词汇量/背景知识→理解能力→成绩）

梳理后的因果链条：
[培养阅读习惯] → [扩大词汇量和背景知识积累] → [提升阅读理解和信息处理能力] → [学业成绩提升]

写作建议：
明确指出机制——不要只说"阅读让成绩变好"，要说清楚"阅读通过什么机制影响成绩"；同时承认家庭环境是混杂变量，必要时加一句说明
```

### 示例 2：因果倒置

**输入：**
> 我写了"因为年轻人不愿意生育，所以中国的生育率下降了"
> 但感觉逻辑上说不通

**输出：**
```
【因果关系梳理】
作者的主张：年轻人不愿生育→生育率下降

因果检验：
　时间顺序：生育率是统计结果，它本身就是由生育意愿决定的——这里不是因果关系，而是定义关系
　问题所在："年轻人不愿意生育"和"生育率下降"说的是同一件事的不同表述，而非因果关系

诊断：
　因果方向：这不是因果，是循环定义（不愿生育=生育率低）
　真正的因果链应该往前追溯：是什么导致年轻人不愿生育

梳理后的因果链条（建议重写方向）：
[房价高/养育成本高] + [职业发展压力] + [生育观念变化] → [年轻人推迟或放弃生育决策] → [生育率下降]

写作建议：
把"年轻人不愿意生育"作为中间现象，而非原因。文章的逻辑应该是：找到真正的原因（经济压力/观念变化）→解释为什么这些原因导致年轻人不愿生育→再指出结果是生育率下降
```

## Best Practices

- 因果倒置在口语写作中极为常见，要特别注意"A是B的结果"被写成"因为A所以B"的情况。
- 多步因果链条中，每一步都要能经受"为什么"的追问；如果某步说不清楚，就是有缺口，参考 `logic-bridge`。
- 对于社会科学类话题，因果关系通常是概率性的而非确定性的，表述时要加限定（"在大多数情况下""研究显示"）。

## Edge Cases

- **真的是双向因果（互为因果）**：告知作者这种关系叫"正反馈循环"，写法上要明确说明循环机制，而不是简单地"A导致B"。
- **作者要论证的因果关系实际不成立**：直接指出，并帮助找到更准确的表达（如"A与B相关"而非"A导致B"）。
- **因果链条太长（超过4步）**：建议聚焦最关键的2-3步，过长的链条在文章中难以清晰表达。
