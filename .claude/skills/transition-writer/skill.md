# 过渡衔接

本技能解决两段内容之间跳跃感强、衔接生硬的问题。通过分析上下段的逻辑关系，提供流畅自然的过渡方案。

## Workflow

### 第一步：分析两段的逻辑关系

读取上段结尾和下段开头（或主题），判断两段之间是什么逻辑关系：

| 逻辑关系 | 说明 | 典型连接词 |
|---------|------|-----------|
| 递进 | 下段是上段的深化或延伸 | 更进一步、不仅如此、在此基础上 |
| 转折 | 下段与上段形成对比或转向 | 然而、但是、另一方面 |
| 因果 | 上段是原因，下段是结果（或反之） | 正因如此、由此可见、这导致了 |
| 举例 | 下段是上段观点的具体案例 | 以……为例、举个例子 |
| 总分 | 上段是总述，下段是分述（或反之） | 具体来说、首先…其次… |
| 时间 | 按时间顺序推进 | 随后、与此同时、几年后 |
| 话题转换 | 两段话题不同，需要显式过渡 | 说完A，再来看B |

### 第二步：诊断跳跃感来源

| 跳跃原因 | 表现 |
|---------|------|
| 话题切换太突兀 | 上段和下段说的是完全不同的事 |
| 缺少逻辑连接词 | 两段内容有关系但没说清楚是什么关系 |
| 情绪/节奏断层 | 上段是平静叙述，下段突然激动（或反之） |
| 视角切换未提示 | 叙述视角从"我"切到"他"，没有交代 |

### 第三步：提供过渡方案

给出 2-3 种过渡方案，每种包含：
- **过渡类型**
- **具体过渡句**（可直接使用或参考）
- **适合的场景和理由**

### 第四步：输出结果

```
【过渡衔接方案】
两段逻辑关系：[识别结果]
跳跃原因：[诊断]

方案 A（[过渡类型]）：
"[具体过渡句，1-3句]"
适合场景：[什么情况下用这个方案]

方案 B（[过渡类型]）：
"[具体过渡句，1-3句]"
适合场景：[什么情况下用这个方案]

方案 C（[过渡类型]）：（可选）
"[具体过渡句，1-3句]"
适合场景：[什么情况下用这个方案]

推荐：方案 [X]，原因：[一句话]
```

## Usage

提供上段的最后 1-3 句话，以及下段的第一句话或段落主题。如知道文章整体语气，一并说明。

## Examples

### 示例 1：议论文话题转换

**输入：**
> 上段结尾：…因此，提高生产效率是企业在竞争中脱颖而出的关键。
> 下段主题：要讲企业文化建设的重要性
> 文章语气：正式、商业

**输出：**
```
【过渡衔接方案】
两段逻辑关系：话题转换（从"效率"转向"文化"，两者都是企业竞争力的组成部分）
跳跃原因：两个话题之间没有建立显式的并列或递进关系

方案 A（并列过渡）：
"效率解决了'能做多少'的问题，而企业文化决定了'愿意做多少'。"
适合场景：想强调两者同等重要，不分主次

方案 B（递进过渡）：
"提高效率是必要条件，但仅靠效率还不够——真正让企业持续领跑的，是内部文化的凝聚力。"
适合场景：想暗示文化比效率更重要，为下段论证做铺垫

方案 C（提问过渡）：
"那么，当所有竞争者的生产效率都相近时，企业靠什么拉开差距？"
适合场景：想制造悬念，引导读者带着问题读下段

推荐：方案 B，原因：结合文章已有的论证逻辑，效率在前文已有充分论述，此处过渡应把"文化"的地位拔高
```

### 示例 2：散文情绪节奏断层

**输入：**
> 上段结尾：…那个下午，阳光把整个院子都铺满了，什么都是暖的。
> 下段开头想写：外婆去世的消息
> 文章语气：散文，平和

**输出：**
```
【过渡衔接方案】
两段逻辑关系：时间推进，情绪从温暖转为悲伤
跳跃原因：情绪落差极大，需要一个缓冲，否则转折会显得残忍或刻意

方案 A（时间过渡 + 情绪预告）：
"那是我最后一次在那个院子里晒到那样的阳光。"
适合场景：不直接说消息，让读者自己感受到转折的重量

方案 B（时间跳跃 + 平静叙述）：
"三个月后，母亲打来电话。"
适合场景：用极简的句子切换，把情绪重量留给下段的内容

方案 C（感受过渡）：
"我后来常常想起那个下午。大概是因为，它是'之前'最后留给我的记忆。"
适合场景：用回望视角建立过渡，适合全篇是追忆视角的散文

推荐：方案 A，原因：散文的力量在于克制，用"最后一次"这样的暗示比直接说消息更有余韵
```

## Best Practices

- 过渡句应融入文章，不应像"接下来我们讨论……"这种教科书式的转场。
- 散文和小说的过渡要保持情感温度，不能太机械；议论文和报告的过渡要清晰，不能太含糊。
- 如果上下段之间的跳跃感来自内容本身的问题（而不是衔接），建议先用 `outline-expander` 解决结构，再处理过渡。

## Edge Cases

- **两段内容完全无关**：过渡句无法弥补内容本身的断裂，建议先重新考虑段落顺序或删除一段。
- **作者只提供了段落主题，没有具体内容**：可以给出方向性建议，但无法提供精确的过渡句，会在方案中标注。
- **需要过渡的段落超过两段**：建议逐对处理，一次只处理相邻两段之间的关系。
