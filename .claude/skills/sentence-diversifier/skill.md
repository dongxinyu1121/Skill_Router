# 句式多样化

本技能解决"句子结构太相似，读起来单调乏味"的语言类卡壳。通过分析句式模式，帮助作者增加句子的节奏变化，让文章读起来更有生命力。

## Workflow

### 第一步：识别句式单调的模式

扫描已写内容，识别：

| 问题类型 | 表现 |
|---------|------|
| 长度单调 | 所有句子差不多一样长（都是长句，或都是短句） |
| 结构单调 | 大量使用同一种句式（"A是B""A导致B""首先…其次…"） |
| 开头单调 | 每句话都以同样的方式开头（都是主语开头，或都用"我"开头） |
| 节奏单调 | 缺少节奏的轻重起伏，读起来像念经 |

### 第二步：分析节奏理想状态

好的文章节奏应该有：
- **长短交替**：长句铺陈，短句收力
- **结构变化**：陈述句、问句、感叹句、倒装句交替
- **开头变化**：主语、状语、时间词、感受词轮换
- **密度变化**：信息密集的长句之后，跟一个简洁有力的短句

经典节奏模式：**长-长-短**（两句铺陈，一句收束）

### 第三步：提供改写建议

针对识别出的问题，给出：
- 2-3种可以立刻应用的句式变化方法
- 把文中一个单调段落改写成有节奏变化的版本

### 第四步：输出结果

```
【句式多样化分析】
识别到的问题：
　[具体的句式单调类型]

目前主要句式模式：[描述当前句式的特征]

改写技巧：

技巧 1：[名称] — [说明]
技巧 2：[名称] — [说明]
技巧 3：[名称] — [说明]

改写示例：
原段落：
"[原来的段落]"

改写后：
"[改写后的段落]"

改写说明：[做了哪些句式调整]
```

## Usage

提供需要改善句式节奏的段落，本技能自动分析并给出改写建议。

## Examples

### 示例 1：全是长句，缺少节奏

**输入：**
> 远程工作已经成为很多人工作方式的新常态，它改变了人们对于工作地点和时间的传统认知，让更多人能够在家中或者任何地方完成以前只能在办公室里做的事情，同时也带来了一些新的挑战，比如工作和生活边界模糊、缺乏面对面的社交互动以及自我管理能力的要求提升。

**输出：**
```
【句式多样化分析】
识别到的问题：
　全文是一个超长复合句，所有信息堆在一起，读者喘不过气
　缺乏节奏停顿点
　信息量过大，重点被淹没

改写技巧：

技巧 1：断句——把复合句拆成多个短句，每个句子只说一件事
技巧 2：长短交替——用长句说复杂信息，用短句强调重点
技巧 3：用问句制造节奏停顿

改写后：
远程工作已经不是例外，而是常态。
越来越多的人开始在家中、在咖啡馆、在任何有网络的地方完成以前必须坐进格子间才能做的事情——这是一种解放，也是一种考验。
工作和生活的边界模糊了。没有了下班的铃声，你怎么知道今天结束了？

改写说明：
- 第一句变成极短的陈述句，有冲击力
- 第二句是长句，铺陈变化的具体内容，后半句"这是一种解放，也是一种考验"用对比收束
- 第三句短句，提炼核心问题
- 最后用一个问句，把"挑战"变成一个真实的问题，而不是罗列项目
```

### 示例 2：开头单调（全是"我"开头）

**输入：**
> 我喜欢早上喝咖啡。我觉得咖啡让我清醒。我每天都会去附近的咖啡店。我最喜欢那里的美式。我在那里工作了很多个早晨。

**输出：**
```
【句式多样化分析】
识别到的问题：
　每句话都以"我"开头，节奏像打鼓——单调且缺乏变化
　句子长度也差不多，加重了单调感

改写技巧：

技巧 1：换开头——把状语、时间词、感受词或物件名称提到句首
技巧 2：合并——把相关的两句合并成一个有层次的句子
技巧 3：变换视角——偶尔不从"我"出发，从物件或场景出发

改写后：
早上不喝咖啡，整个人是飘的。
附近有一家小咖啡店，我几乎每天去，点的永远是美式。
坐在靠窗的位置，能看见上班的人经过，咖啡还烫的时候最适合工作。
那些早晨，大概是一天里最好的两个小时。

改写说明：
- 第一句以"早上"开头，用感受而非"我喜欢"引出话题
- 第二句合并了两个信息（去咖啡店+喝美式），更流畅
- 第三句从"坐在靠窗的位置"（场景）开头，不是"我"
- 最后一句是总结式短句，给段落收束感
```

## Best Practices

- 节奏变化的核心是"长-短对比"——长句之后放一个短句，效果往往立竿见影。
- 不是每句话都需要不同结构——战略性的重复有时候是节奏的一部分（如排比），重点是有意识地选择，而不是无意识的单调。
- 改写时，优先调整最影响阅读体验的地方（通常是连续三句以上完全相同结构的地方）。

## Edge Cases

- **作者刻意使用排比句**：确认是否为有意的修辞选择，如果是，则不建议打破这个结构。
- **文章已经有节奏感但作者不满意**：可能是用词问题而非句式问题，建议同时使用 `word-variety-expander`。
- **技术或学术文章**：这类文章以清晰为优先，句式变化的空间较小，重点放在避免超长句子，而不是追求文学节奏感。
