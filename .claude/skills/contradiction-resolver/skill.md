# 自我矛盾处理

本技能解决议论文或说理性文章中"前后观点互相打架"的逻辑类卡壳。当作者发现已写内容之间存在矛盾，或者想写的下一段会和前文冲突，本技能帮助定位矛盾、分析原因并给出处理策略。

## Workflow

### 第一步：定位矛盾

阅读全文，识别以下类型的矛盾：

| 矛盾类型 | 表现 |
|---------|------|
| 直接矛盾 | 同一文章中两处对同一问题给出相反的判断 |
| 标准矛盾 | 用不同的标准评价同类事物（A满足X就说好，B满足同样的X却说不好） |
| 前提矛盾 | 论证A时假设了X，论证B时又假设了非X |
| 隐性矛盾 | 单独看每段都成立，但放在一起推导出矛盾的结论 |

### 第二步：分析矛盾原因

| 原因 | 说明 |
|------|------|
| 观点确实在写作中发生了变化 | 作者越写越觉得原来的立场有问题 |
| 举例时用力过猛 | 为了支持某个论点用了一个例子，但这个例子实际上反驳了别的地方 |
| 语言不精确 | 前后用了同一个词，但含义实际不同 |
| 论证范围混淆 | 前面的论点只在特定条件下成立，但后面当作普遍规律使用 |

### 第三步：提供三种处理策略

| 策略 | 适用场景 |
|------|---------|
| 修改前段 | 前段的表述过于绝对，收窄论点范围可以消除矛盾 |
| 修改后段 | 后段的论证方向可以调整，绕开矛盾点 |
| 承认并整合矛盾 | 两个观点都成立但适用场景不同，可以在文章中明确说明 |

### 第四步：输出结果

```
【自我矛盾处理】
矛盾位置：
　观点A（[位置]）："[具体表述]"
　观点B（[位置]）："[具体表述]"
矛盾类型：[矛盾类型]
矛盾原因：[分析]

处理策略：

策略1（修改前段）：[具体怎么修改，改成什么意思]
策略2（修改后段）：[具体怎么调整方向]
策略3（整合矛盾）：[如果两个观点都想保留，怎么用"条件限定"的方式共存]

推荐：策略 [X]，原因：[一句话]
```

## Usage

提供全部已写内容，并指出你发现的矛盾在哪里（如果不确定，本技能会自动检查）。

## Examples

### 示例 1：直接矛盾

**输入：**
> 第二段："社交媒体让人们更容易建立真实的情感连接，因为它打破了地理限制。"
> 第五段："社交媒体上的关系是虚假的，缺乏真实的情感深度。"

**输出：**
```
【自我矛盾处理】
矛盾位置：
　观点A（第二段）："社交媒体让人更容易建立真实的情感连接"
　观点B（第五段）："社交媒体上的关系缺乏真实情感深度"
矛盾类型：直接矛盾（对同一事物给出相反判断）
矛盾原因：两段分别关注了社交媒体的不同功能，但都使用了绝对化的表述，导致冲突

处理策略：

策略1（修改前段）：
将"更容易建立真实的情感连接"改为"更容易建立初步联系"——承认社交媒体降低了连接门槛，但初步连接不等于深度情感关系

策略2（修改后段）：
将"关系是虚假的"改为"在没有线下互动支撑的情况下，关系难以发展出深度"——把绝对判断改为有条件的判断

策略3（整合矛盾）：
两个观点都成立，但适用于不同阶段——"社交媒体擅长建立连接，但真实的情感深度仍需要线下互动来完成"，在文章中明确这个区分

推荐：策略3，原因：两个观点各自都有价值，整合后的论点更完整，也更符合真实情况
```

### 示例 2：论证范围混淆

**输入：**
> 第三段论证"在高压力环境下，人的决策质量会下降"（引用了相关研究）
> 第六段想写"因此，企业不应该给员工施加任何压力"

**输出：**
```
【自我矛盾处理】
矛盾位置：
　观点A（第三段）：高压力会导致决策质量下降（研究支撑，成立）
　观点B（第六段想写）：企业不应给员工任何压力（由A推导，但范围扩大了）
矛盾类型：前提矛盾（研究只说明了"高压力"的危害，但结论跳到了"任何压力"）
矛盾原因：论证范围从"高压力"扩大到了"所有压力"，而适度压力实际上有助于激励和效率

处理策略：

策略1（修改后段结论）：
将"不应给员工任何压力"改为"不应给员工持续性的高强度压力"——与研究结论保持一致的范围

策略2（补充前段的限定条件）：
在第三段补充：所指的"高压力"是指持续性、无法预期、无法控制的压力，与适度的挑战性压力不同

策略3（整合矛盾）：
在第六段明确区分两种压力——"挑战性压力（可以激发动力）"vs"威胁性压力（损害决策）"，企业应消除后者而非前者

推荐：策略1，原因：最简单直接，只需修改结论句，不需要大幅改动前文
```

## Best Practices

- 矛盾不一定是逻辑错误，有时是观点真的在写作中发生了进化——此时帮助作者明确"新观点是什么"比修补矛盾更重要。
- 不替作者决定保留哪个观点，策略选择权在作者。
- 隐性矛盾最难发现，需要将两个表面无关的段落放在一起推导，看结论是否冲突。

## Edge Cases

- **作者说"我就是想同时表达两个矛盾的观点"**：可以，但需要在文章中明确说明这是一个悖论，而不是不加说明地让两个结论共存。
- **矛盾来自引用了两个相互矛盾的研究**：建议作者选择一个立场，或者专门写一段处理这个学术分歧。
- **找不到明显矛盾，但作者感觉有**：逐段提取每段的核心主张，看列在一起是否产生冲突。
