# 大纲推演

本技能用于解决结构类卡壳：作者已写完某段内容，但不知道接下来该写什么。通过分析已有内容的结构逻辑和当前进展，推演出下一段的合理方向。

## Workflow

### 第一步：梳理已有结构

阅读全部已写内容，提取：

- **文章类型**：议论文 / 说明文 / 散文 / 报告
- **核心主题**：文章最终想说的是什么
- **已覆盖的层次**：哪些内容已经写了
- **当前位置**：文章处于开头 / 中段 / 接近结尾

### 第二步：识别结构缺口

根据文章类型，对照常见结构模型判断缺少什么：

| 文章类型 | 常见结构 | 缺口识别方式 |
|---------|---------|------------|
| 议论文 | 提出问题 → 分析原因 → 论证 → 结论 | 看论证链条缺哪一环 |
| 说明文 | 是什么 → 为什么 → 怎么做 | 看三问哪个没回答 |
| 散文 | 起点（触发） → 展开（联想） → 落脚 | 看情感/思路有没有完成闭环 |
| 报告 | 背景 → 发现 → 分析 → 建议 | 看四段哪个缺失 |

### 第三步：推演下一步方向

基于结构缺口，提出 2-3 个下一步方向，每个方向包含：
- 段落主题：这一段要论述或描述什么
- 逻辑功能：在整体结构中起什么作用
- 示例开头句：帮助作者启动写作的第一句话

### 第四步：给出推荐

在多个方向中，推荐最符合文章整体意图的一个，并简要说明理由。

```
【大纲推演结果】
当前进展：[一句话总结文章写到哪里了]
结构缺口：[目前缺少的结构层次]

方向 A：[段落主题]
　功能：[在结构中的作用]
　示例开头："[开头句]"

方向 B：[段落主题]
　功能：[在结构中的作用]
　示例开头："[开头句]"

方向 C：[段落主题]（可选）
　功能：[在结构中的作用]
　示例开头："[开头句]"

推荐：方向 [X]，原因：[一句话]
```

## Usage

粘贴已写内容，并告知文章类型（如不告知则自动判断）。如有原始大纲，一并提供。

## Examples

### 示例 1：议论文结构推演

**输入：**
> 文章类型：议论文
> 已写内容：提出了"年轻人应该尽早规划职业路径"的观点，并用两段分析了提早规划的必要性。

**输出：**
```
【大纲推演结果】
当前进展：观点已提出，必要性已论证，尚未进入"如何做"和"结论"阶段
结构缺口：缺少具体论证支撑（案例/数据）和可操作的建议部分

方向 A：用真实案例支撑论点
　功能：强化已有论证的说服力
　示例开头："以科技行业为例，那些在校期间就明确方向的人……"

方向 B：分析不规划的代价（反向论证）
　功能：通过对比放大主张的价值
　示例开头："没有规划并不意味着自由，更多时候意味着……"

方向 C：提出具体的规划路径建议
　功能：从论证转向操作，给读者实际抓手
　示例开头："规划不需要做到十年规划，从三件事开始就够了……"

推荐：方向 C，原因：前两段已完成论证，读者此时更需要的是"怎么做"
```

### 示例 2：散文结构推演

**输入：**
> 已写内容：描述了一次坐绿皮火车的旅途见闻，车窗外的风景、同车厢的陌生人、饭盒的气味。

**输出：**
```
【大纲推演结果】
当前进展：感官细节铺陈充分，尚未进入情感升华或主题落脚阶段
结构缺口：缺少从"见闻"到"感受"的转折，以及文章的情感落脚点

方向 A：从某个细节引发内心感受
　功能：完成从外部描述到内心世界的过渡
　示例开头："那个抱着孩子睡着的女人，让我想起了很多年前的……"

方向 B：直接跳到旅途结束时的心境
　功能：用时间跳跃拉开距离感，制造回望视角
　示例开头："火车到站的一刻，我突然不想下去了。"

推荐：方向 A，原因：当前内容以细节见长，从细节自然引发情感更符合散文逻辑
```

## Best Practices

- 不替作者写正文，只提供方向和示例句；示例句控制在 20 字以内，只需启动作者的写作状态。
- 如果原有大纲和已写内容出现偏差，优先以已写内容为准，并在结果中注明偏差情况。
- 方向之间应有实质差异，不要给出三个本质相同的方向。

## Edge Cases

- **文章只有一两句话**：无法判断结构，要求作者提供写作意图或大纲。
- **文章已接近结尾**：不推荐续写方向，改为建议使用 `ending-designer`。
- **作者提供了大纲但没有已写内容**：基于大纲进行推演，同时提醒作者推演结果可能随写作调整。
