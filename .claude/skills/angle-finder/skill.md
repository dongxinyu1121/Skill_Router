# 切入角度

本技能解决"知道要写什么，但不知道怎么开始写"的卡壳。当作者对段落主题清楚，但每次下笔都感觉不对，本技能帮助找到最合适的切入角度。

## Workflow

### 第一步：理解目标段落

明确以下两点：
- **这段要表达的核心内容**：作者想说的那件事是什么
- **上下文风格**：前后内容的语气、节奏、叙述方式

### 第二步：分析为什么卡壳

切入卡壳通常来自以下原因之一：

| 原因 | 表现 |
|------|------|
| 角度太大 | 想从"宏观"切入，但宏观叙述容易空洞 |
| 角度太小 | 陷入一个细节，无法自然引出主题 |
| 惯性角度 | 总是用同一种方式切入（如"首先……"），读起来模板化 |
| 情感距离不对 | 理性内容需要感性入口，或感性内容需要具体事件触发 |

### 第三步：提供多种切入角度

从以下角度类型中，选取最适合当前段落的 3 种：

| 角度类型 | 说明 | 适合场景 |
|---------|------|---------|
| 场景切入 | 从一个具体的画面或事件开始 | 散文、叙事、渲染氛围 |
| 疑问切入 | 以问题引出话题 | 议论文、说明文、吸引读者思考 |
| 对比切入 | 先说反面或对立情况，再转入主题 | 议论文、强调反差 |
| 数据切入 | 以令人意外的数字或事实开场 | 说服类、新闻类 |
| 情感切入 | 从一种感受或情绪直接进入 | 散文、建立共鸣 |
| 引用切入 | 用他人的话或名言引入 | 议论文、增加分量 |
| 细节切入 | 从一个非常具体的小细节放大 | 散文、文学性写作 |

### 第四步：输出结果

```
【切入角度建议】
要表达的核心内容：[一句话概括]
当前卡壳原因：[为什么下不了笔]

角度 A（[切入类型]）：
　思路：[怎么切入]
　示例开头："[开头句]"
　适合原因：[一句话]

角度 B（[切入类型]）：
　思路：[怎么切入]
　示例开头："[开头句]"
　适合原因：[一句话]

角度 C（[切入类型]）：
　思路：[怎么切入]
　示例开头："[开头句]"
　适合原因：[一句话]

推荐：角度 [X]，因为[一句话]
```

## Usage

提供要写的段落主题和上下文（前一段的结尾），以及作者已经尝试过但感觉不对的写法（如有）。

## Examples

### 示例 1：议论文段落切入

**输入：**
> 上下文：文章讨论城市噪音污染问题
> 这段要写：噪音对睡眠的影响
> 尝试过的写法："噪音对睡眠影响很大，研究表明……"感觉太平了

**输出：**
```
【切入角度建议】
要表达的核心内容：噪音会损害睡眠质量，进而影响健康
当前卡壳原因：从"研究表明"切入太过平直，缺少让读者产生代入感的入口

角度 A（场景切入）：
　思路：从一个凌晨被噪音吵醒的具体场景切入
　示例开头："凌晨两点，一辆改装摩托车的轰鸣让整条街同时睁开了眼睛。"
　适合原因：让读者立刻产生共鸣，再引入数据会更有说服力

角度 B（数据切入）：
　思路：用一个意外的数字开场
　示例开头："世界卫生组织的数据显示，长期暴露在65分贝以上的噪音中，心脏病风险提升20%。"
　适合原因：数字本身足够令人意外，能直接抓住读者注意力

角度 C（疑问切入）：
　思路：以一个生活化的问题引入
　示例开头："你上一次一觉睡到天亮，是什么时候？"
　适合原因：让读者对号入座，主动思考噪音与自己的关系

推荐：角度 A，因为前文已有数据支撑，此处用场景切入可以调节节奏，避免全文都是数据堆砌
```

### 示例 2：散文段落切入

**输入：**
> 上下文：写外婆的散文，前面写了外婆的外貌
> 这段要写：外婆做饭的习惯
> 卡壳：不知道从哪里开始

**输出：**
```
【切入角度建议】
要表达的核心内容：外婆做饭的某个独特习惯，体现她的性格或与我的情感连接
当前卡壳原因：目标太宽泛，"做饭的习惯"有无数个，需要找到一个最有感情重量的切入点

角度 A（细节切入）：
　思路：从一个极具体的物件或动作放大
　示例开头："外婆切葱的时候永远是斜刀，切出来的每一片都像半个月亮。"
　适合原因：细节本身就是人物，从这里展开自然会带出她的性格

角度 B（情感切入）：
　思路：从"我"对这件事的感受切入
　示例开头："在外婆家待久了，你会发现：锅铲碰锅沿的那声响，比任何闹钟都管用。"
　适合原因：从感受而非描述进入，更有散文的情感温度

角度 C（场景切入）：
　思路：重建一个具体的做饭场景
　示例开头："每天早上六点，厨房的灯是全家最先亮起来的。"
　适合原因：用时间和动作构建画面，读者跟着走进场景

推荐：角度 A，因为散文的力量在于细节的精准，一个月亮形的葱段比"她很细心"有力量得多
```

## Best Practices

- 示例开头句控制在 30 字以内，只需给出启动方向，不是要写完整段落。
- 三个角度之间要有实质差异，不能给三个本质相同的切入方式。
- 角度推荐要结合上下文风格，不能给出和前文语气完全不符的方向。

## Edge Cases

- **作者完全不知道这段要写什么**：本技能无法使用，建议先用 `outline-expander` 确定段落主题。
- **作者已经有了一个角度，但执行起来卡壳**：可能是素材不足，建议同时参考 `detail-generator`。
- **文章有特定体裁限制**（如命题作文、规范报告）：优先推荐符合体裁惯例的切入方式，不推荐过于文学化的角度。
