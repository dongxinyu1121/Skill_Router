# 引子强化

本技能解决"开头写了，但感觉没有吸引力，读者可能看了第一句就放弃"的开头类卡壳。通过分析引子的问题，帮助作者写出让读者想继续读的开头。

## Workflow

### 第一步：诊断引子的问题类型

| 问题类型 | 表现 |
|---------|------|
| 起点太高 | 开头太宏观，从"人类社会""自古以来"开始 |
| 说废话 | 开头是读者已经知道的常识，没有任何新信息 |
| 直接进入论证 | 没有"钩子"，直接开始说论点，读者还没有被吸引就要开始接收信息 |
| 过于谦虚/平淡 | "本文将讨论……""我想聊一聊……"这类没有吸引力的开场 |
| 悬念不足 | 开头把所有信息都交代完了，读者没有继续读的理由 |

### 第二步：分析有效钩子的类型

| 钩子类型 | 原理 | 示例形式 |
|---------|------|---------|
| 反常识钩子 | 说出一个违反读者预期的事实或观点 | "你以为努力工作就能成功？数据说不是。" |
| 悬念钩子 | 提出一个问题或情境，但不立刻给答案 | "那天她做了一个决定，让所有人都看错了她。" |
| 场景钩子 | 把读者扔进一个具体的画面里 | "2020年3月，一个程序员在上海的出租屋里，决定辞职。" |
| 数字钩子 | 用意外的数字开场 | "94%的人在读完一本书后，三天内忘掉大部分内容。" |
| 共鸣钩子 | 说出一个读者有过但没有被说出来的感受 | "有时候你知道该怎么做，但就是做不到，这不是意志力的问题。" |
| 故事钩子 | 从一个具体人物的具体行动开始 | "林明在第三家咖啡店门口停下来，看了看时间。" |

### 第三步：提供改写方案

给出 2-3 种不同钩子类型的改写版本，每种附：
- 钩子类型
- 改写后的开头（2-4句）
- 为什么这样写有吸引力

### 第四步：输出结果

```
【引子强化分析】
原有引子："[原来的开头]"
问题诊断：[引子的主要问题]

改写方案：

方案 A（[钩子类型]）：
"[改写后的开头，2-4句]"
吸引力来源：[为什么读者会想继续读]

方案 B（[钩子类型]）：
"[改写后的开头，2-4句]"
吸引力来源：[为什么读者会想继续读]

方案 C（[钩子类型]）：（可选）
"[改写后的开头，2-4句]"
吸引力来源：[为什么读者会想继续读]

推荐：方案 [X]，因为[一句话]
```

## Usage

提供当前的开头段落和文章主题，以及文章类型（议论文/散文/故事/科普等）。

## Examples

### 示例 1：起点太高，说废话

**输入：**
> 文章主题：社交媒体对青少年心理健康的影响
> 原有引子：在当今这个信息时代，社交媒体已经成为人们日常生活中不可或缺的一部分，尤其是对于年轻一代来说，社交媒体更是占据了他们大量的时间和注意力。

**输出：**
```
【引子强化分析】
原有引子："在当今这个信息时代……社交媒体占据了他们大量的时间和注意力。"
问题诊断：起点太高（"当今这个信息时代"是无信息量的套语）+ 说废话（这些内容读者都知道，没有任何新信息让人想继续读）

改写方案：

方案 A（数字钩子）：
"一项追踪1万名青少年的研究发现：每天使用社交媒体超过3小时，抑郁风险提升35%。这个数字，很多父母不知道。"
吸引力来源：具体数字有冲击感，"这个数字，很多父母不知道"制造了"我可能不知道"的焦虑，让读者想继续读

方案 B（反常识钩子）：
"我们花了十年时间讨论社交媒体让孩子'更孤独'，但最新研究告诉我们：问题不在于使用多少，而在于怎么用。"
吸引力来源：推翻了读者的既有认知，制造了"原来我理解错了"的悬念

方案 C（场景钩子）：
"她15岁，每天发布三条内容，平均等待时间：7分钟。如果点赞数不够，她会删掉重发。"
吸引力来源：具体人物+具体行为，读者立刻进入场景，想知道"这个女孩怎么了"

推荐：方案 A，因为如果面向家长读者，数字钩子的触动最直接，且立刻建立了文章的信息价值
```

### 示例 2：过于谦虚/平淡

**输入：**
> 文章主题：一篇关于做饭这件事的散文
> 原有引子：我想写一写关于做饭的一些感悟和想法。

**输出：**
```
【引子强化分析】
原有引子："我想写一写关于做饭的一些感悟和想法。"
问题诊断：过于谦虚/平淡——这句话是对文章内容的"预告"，而不是文章本身；没有任何画面或情感，读者没有理由继续读

改写方案：

方案 A（场景钩子）：
"那天我把葱切碎了，还是找不到盐。在厨房站了很久，才想起盐罐放在了洗衣机上。"
吸引力来源：具体场景有生活质感，读者立刻感到亲近，"为什么盐放在洗衣机上"制造了微小的悬念

方案 B（共鸣钩子）：
"我在三十岁之前，从来没有认真做过一顿饭。不是不会，是不屑。"
吸引力来源："不屑"这个词出乎意料，读者想知道是什么改变了这个人

方案 C（细节钩子）：
"油温要七成热——我花了两年才理解这句话是什么意思。"
吸引力来源：一个具体的细节加一段时间，暗示了一段学习和改变的故事，读者想知道后来发生了什么

推荐：方案 B，因为散文的力量在于真实和坦诚，"不屑"这个词既真实又出乎意料，最有继续读的驱动力
```

## Best Practices

- 好的开头不需要炫技，但必须给读者一个继续读的理由——要么有新信息，要么有悬念，要么有共鸣。
- "自古以来""在今天这个时代"等套语是最弱的开头，永远不要这样开始。
- 改写开头时，要确保新的开头和文章整体内容匹配——钩子必须能兑现，不能只是为了吸引而吸引。

## Edge Cases

- **命题作文有固定格式要求**：在格式约束内找钩子，通常可以在第一句话里加入一个意外的角度或具体的细节。
- **开头已经很好但作者不确定**：使用 `quality-assessor` 做客观评估，而不是直接改写。
- **文章开头和文章主体脱节**：钩子设置的悬念没有在后续兑现，建议调整文章主体而不是只改开头。
