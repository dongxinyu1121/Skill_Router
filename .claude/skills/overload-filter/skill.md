# 信息过滤

本技能解决"收集了太多素材，不知道用哪些"的信息取舍类卡壳。当作者面对大量资料、案例、数据，感到无从下手，本技能帮助建立筛选框架，快速找到最应该用的内容。

## Workflow

### 第一步：明确文章的核心需求

在筛选素材之前，必须先确认：
- **文章的核心论点或主题是什么**
- **目标读者是谁**
- **文章类型**（议论 / 说明 / 叙事）

这三点决定了什么素材有价值。

### 第二步：建立素材筛选标准

用三个维度评估每条素材：

| 维度 | 问题 | 评分 |
|------|------|------|
| 相关性 | 这条素材直接支持核心论点/主题吗？ | 高/中/低 |
| 典型性 | 这条素材对读者有代表性还是过于特殊？ | 高/中/低 |
| 新鲜度 | 这条素材是读者可能已经知道的，还是新信息？ | 高/中/低 |

最优先使用：三维度都高的素材。
次优先：相关性高但另外一项偏低的素材。
不使用：相关性低的素材，无论其他维度多高。

### 第三步：识别素材的功能角色

每条素材在文章中只能扮演一个功能：

| 功能 | 说明 |
|------|------|
| 核心论据 | 直接支撑主要论点 |
| 辅助论据 | 支撑分论点 |
| 举例说明 | 使论点具体化 |
| 背景铺垫 | 建立语境 |
| 对比材料 | 通过对比强化论点 |

每个功能位置只需要最好的1-2条素材，多余的删掉。

### 第四步：输出结果

```
【素材筛选建议】
核心论点：[确认]
目标读者：[确认]

筛选框架：
　必须用（直接支撑核心论点且典型）：[列出]
　可以用（辅助支撑但价值次要）：[列出]
　建议不用（相关性低或和已选素材重复）：[列出]

功能分配：
　核心论据位置：[推荐哪条素材]
　举例说明位置：[推荐哪条素材]
　背景铺垫位置：[推荐哪条素材]（可选）

删减依据：[为什么建议删去某些素材]
```

## Usage

列出你收集的素材（可以是简短描述），并说明文章的核心论点和目标读者。

## Examples

### 示例 1：议论文素材过多

**输入：**
> 核心论点：长期使用社交媒体损害青少年心理健康
> 素材：
> A. 2023年某研究：每天使用社交媒体超过3小时的青少年抑郁风险高35%
> B. 一位心理咨询师的观察：她的青少年来访者90%都过度使用手机
> C. 社交媒体的发展历史（从Facebook到TikTok）
> D. 某名人说过一句话，大意是社交媒体让年轻人失去了真实连接
> E. 另一项研究：社交媒体使用和睡眠质量下降相关
> F. 一个高中生的案例：她因为被网络霸凌而患上焦虑症

**输出：**
```
【素材筛选建议】
核心论点：长期使用社交媒体损害青少年心理健康
目标读者：家长、教育工作者、政策制定者

筛选结果：

必须用：
　A（研究数据）：直接支撑，数字具体，相关性高，典型性高
　E（睡眠研究）：补充了"心理健康"的另一个维度（睡眠），增加论证宽度
　F（高中生案例）：提供人性化的具体案例，防止文章太抽象

可以用：
　B（咨询师观察）：提供专业视角，但需要补充她的资质背景；可作为辅助论据

建议不用：
　C（社交媒体历史）：相关性低，是背景知识而非论据，读者看了不会更相信论点
　D（名人语录）：名人说的不等于事实，用作论据缺乏说服力；可考虑作为开头引用，但不作为论据

功能分配：
　核心论据：A（数据直接支撑）
　补充论据：E（扩展心理健康的范围）
　举例说明：F（使论点具体可感）
　专业背书：B（辅助，需要补充来源说明）

删减依据：C是背景知识，不是论证；D名人观点无论证效力；B、E如果篇幅有限，B可以省略
```

## Best Practices

- 筛选标准以"相关性"为第一优先，一条无论多精彩的素材，如果和核心论点无关，都应该删去。
- 同类素材只选最好的一条，不要用三条都说同一件事的素材，这是最常见的冗余来源。
- 删去的素材可以保存，有些适合在另一篇文章里使用。

## Edge Cases

- **作者还没有明确核心论点**：无法筛选，先用 `purpose-clarifier` 或 `theme-retriever` 确认核心。
- **所有素材都很重要，舍不得删**：提醒作者一篇文章需要有主次，读者注意力有限；帮助排出优先级而不是"全部用上"。
- **素材太少而不是太多**：本技能不适用，使用 `detail-generator` 寻找补充方向。
