# writing-unstuck 技能体系 · 工作总结

**日期：** 2026-05-29
**项目：** writing-unstuck — 写作卡壳辅助技能体系

---

## 一、项目背景

写作者在创作过程中频繁遭遇"卡壳"——写到一半不知道怎么继续。现有工具缺乏针对性的分类支持，作者往往只能在模糊的焦虑中停滞。本项目旨在构建一套结构化的 AI 技能体系，帮助作者快速定位卡壳原因，并获得可直接使用的续写建议。

---

## 二、设计过程

### 2.1 卡壳类型梳理

通过多轮分析与讨论，将写作卡壳从最初的 3 类（结构/素材/表达）逐步扩展，最终归纳出 **15 大类 35 种卡壳场景**：

| 类别 | 技能数 | 代表场景 |
|------|--------|---------|
| 结构类 | 3 | 大纲断了、议论文逻辑链断、小说情节走不下去 |
| 素材类 | 3 | 细节不够、切入角度找不到、两段衔接不上 |
| 风格类 | 2 | 语气中途变味、找不回自己的写作声音 |
| 结尾类 | 1 | 内容写完了但不知道怎么收 |
| 方向类 | 3 | 主题漂移、目的迷失、不知道在哪里停 |
| 逻辑类 | 3 | 前后矛盾、论证缺口、因果关系不清 |
| 情绪类 | 3 | 热情耗尽、完美主义瘫痪、自我怀疑 |
| 节奏类 | 2 | 某段展开过细、整体比例失衡 |
| 读者类 | 1 | 受众模糊、深浅拿捏不准 |
| 信息取舍类 | 2 | 素材太多不知取舍、知识边界不足 |
| 人物角色类 | 2 | 角色行为不合理、对话不像真人 |
| 创意类 | 2 | 想法平庸、脑子完全空白 |
| 语言类 | 2 | 用词重复、句式单调 |
| 开头类 | 2 | 新段落不知怎么切入、引子吸引力不足 |
| 整合类 | 2 | 多话题不知道怎么拼、资料不知道怎么排序 |

### 2.2 系统架构设计

采用 **诊断层 + 专项技能层** 的两层架构：

```
作者卡壳
    ↓
writing-diagnose（诊断入口）
    ↓ 识别卡壳类型，推荐专项技能
对应专项技能（35 个之一）
    ↓
作者获得具体建议，继续写作
```

- **诊断层**：`writing-diagnose` 作为统一入口，通过阅读已写内容和作者描述，定位卡壳类型并推荐技能
- **直通模式**：作者若已明确卡壳原因，可跳过诊断直接调用对应技能

### 3.2 技能文件规范

每个技能文件均包含以下结构：

- **YAML frontmatter**：name、description、version 等元信息
- **定位说明**：一段话说明本技能适用场景
- **Workflow**：分步骤的执行流程（通常 4 步）
- **Usage**：使用说明和输入格式
- **Examples**：2-3 个带完整输入/输出的示例
- **Best Practices**：3 条最佳实践
- **Edge Cases**：3 条边界情况处理
