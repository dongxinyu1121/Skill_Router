# 打破陈词滥调

本技能解决"想法太普通、写出来的东西和别人没什么不同"的创意类卡壳。通过识别陈词滥调的来源，帮助作者找到属于自己的、新鲜的切入角度。

## Workflow

### 第一步：识别陈词滥调的类型

| 类型 | 表现 | 例子 |
|------|------|------|
| 观点陈词滥调 | 说的是人尽皆知的"正确废话" | "坚持就是胜利" |
| 切入角度陈词滥调 | 用最常见的方式进入一个话题 | 写"母爱"从"小时候生病妈妈陪夜"写起 |
| 意象陈词滥调 | 用被用烂的比喻或意象 | "人生如棋""时光如水" |
| 结构陈词滥调 | 套用固定结构 | 写成功=努力+天赋+机遇的固定公式 |

### 第二步：找到陈词滥调的"反面"

用以下问题挑战现有想法：

**反转法**：把你现在的观点反过来说，有没有道理？
**局部法**：现有观点在什么情况下不成立？把例外情况写出来会怎样？
**视角法**：如果换一个不常见的视角（反派、旁观者、物件本身），会看到什么？
**具体法**：把你说的"宏大"话题缩小到一个极其具体的时刻，那个时刻是什么？

### 第三步：提供新鲜切入角度

给出 3 个打破陈词滥调的方向，每个方向说明：
- 打破的策略
- 具体的切入方式
- 示例句或写作方向

### 第四步：输出结果

```
【陈词滥调诊断与突破】
当前想法/角度：[作者原有的思路]
陈词滥调类型：[属于哪种]
陈词滥调原因：[为什么会落入这个套路]

突破方向：

方向 A（[策略名称]）：
　切入方式：[具体怎么做]
　示例："[开头句或写法示意]"

方向 B（[策略名称]）：
　切入方式：[具体怎么做]
　示例："[开头句或写法示意]"

方向 C（[策略名称]）：
　切入方式：[具体怎么做]
　示例："[开头句或写法示意]"

推荐：方向 [X]，因为[一句话]
```

## Usage

描述你想写的话题和你目前想到的切入角度（或者已经写了但觉得很普通的内容）。

## Examples

### 示例 1：观点陈词滥调

**输入：**
> 话题：写一篇关于"坚持"的文章
> 当前想法：坚持很重要，遇到困难不要放弃，最终会成功

**输出：**
```
【陈词滥调诊断与突破】
当前想法："坚持→成功"的正向励志叙事
陈词滥调类型：观点陈词滥调（正确废话）+ 结构陈词滥调（困难→坚持→成功的固定弧线）
陈词滥调原因：这是关于"坚持"最显而易见的写法，几乎所有人第一个想到的都是这个

突破方向：

方向 A（反转法）：
　切入方式：写"不坚持也是一种智慧"——什么时候应该放弃？放弃比坚持更难？
　示例："我认识最厉害的人，都不是坚持到最后的那个人，而是懂得在哪里停下来的那个。"

方向 B（局部法/反例法）：
　切入方式：聚焦坚持失败的案例——那些坚持了很久但结果并不好的人，他们的坚持是什么？
　示例："他在那份工作上坚持了十二年。我们都叫他'最有毅力的人'。直到他退休的时候说：'我只是不知道还能去哪里。'"

方向 C（具体法）：
　切入方式：把"坚持"落到一个极其具体的时刻，不讨论概念，只写那个时刻
　示例："第八十三天，她打开文档，又删掉了开头的那段话。这已经是第十七次了。她没有再重新写，只是把窗户关上，去煮了一杯茶。"

推荐：方向 B，因为"失败的坚持"比"成功的坚持"罕见，更有说服力，也更接近真实人生
```

### 示例 2：意象陈词滥调

**输入：**
> 散文写故乡，脑子里全是"游子""根""故乡的月亮更圆"这些词，感觉写什么都很俗

**输出：**
```
【陈词滥调诊断与突破】
当前想法：故乡=根、归属感、乡愁的主流叙事
陈词滥调类型：意象陈词滥调（"根""游子""月亮"等被用烂的意象）
陈词滥调原因：故乡类散文有强大的"模板引力"，很容易不自觉地用前人用烂的意象

突破方向：

方向 A（视角法：具体物件的视角）：
　切入方式：不写"故乡"这个抽象概念，而是写故乡里的一个极具体的东西——那个东西可以是你唯一记得的一种声音、一个角落、一种气味
　示例："我所有关于故乡的记忆，最后都会归结到那条排水沟的声音。不是什么诗意的声音，就是雨天水流过去的那种咕噜声。"

方向 B（反转法）：
　切入方式：写"故乡的陌生感"——回去之后发现故乡和记忆中不同，那种错位感比归属感更真实
　示例："我回去的时候，连小卖铺都换了牌子。我找了半天那个老板娘，后来才知道她搬去了城里。所以故乡是什么？是我记得的那个地方，还是那个地方现在的样子？"

方向 C（局部法）：
　切入方式：把"故乡"缩小到一件事、一天、一个人，不写普遍的乡愁，写一个具体的、只属于你的时刻
　示例："关于故乡，我真正珍惜的只是每年春节前几天，大概腊月二十八，全家在厨房忙活、锅气把眼镜片熏成白色的那两个小时。"

推荐：方向 C，因为属于你自己的具体时刻是最有力量的，没有人能复制你的那个记忆
```

## Best Practices

- 陈词滥调的对面不是"刻意求怪"，而是真实——从自己真正经历过、感受过的出发，比从"应该怎么写"出发更有新鲜感。
- "具体法"几乎适用于所有陈词滥调情况——把话题缩小到一个极其具体的时刻，陈词滥调就很难进来。
- 不要因为想"打破陈词滥调"而故意反常，如果反转后的观点本身不成立，就不要用。

## Edge Cases

- **作者认为自己的想法不俗，但读起来很普通**：用"你见过哪篇文章也这样写"来测试——如果能想到很多，就是陈词滥调。
- **话题本身就是老生常谈（如孝顺、友情）**：老话题可以有新角度，重点是找到你自己和这个话题最真实的交叉点。
- **命题作文，不能改变话题**：在话题限制内用"视角法"或"局部法"找切入，而不是反转话题本身。
