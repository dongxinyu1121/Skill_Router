# 写作动力重燃

本技能解决"写到一半对这个题目失去了兴趣"的情绪类卡壳。失去动力通常有具体原因，找到原因比强迫自己硬写更有效。本技能帮助诊断动力流失的根源，并提供重燃热情的策略。

## Workflow

### 第一步：诊断动力流失的原因

| 原因类型 | 表现 | 本质问题 |
|---------|------|---------|
| 题目本身没意思 | 一开始就不太感兴趣，勉强写下去 | 选题问题 |
| 写着写着觉得说不清 | 话题比想象中复杂，没有把握 | 知识边界问题 |
| 感觉写不好 | 越写越觉得和心里的版本差距太大 | 完美主义 / 能力焦虑 |
| 失去了"为什么写"的感觉 | 忘了自己为什么想写这篇文章 | 目的感丢失 |
| 写了太久，疲惫 | 过度投入后的耗竭 | 生理/心理疲劳 |

### 第二步：匹配重燃策略

不同原因对应不同策略：

**针对"目的感丢失"：**
回到原点——为什么想写这篇文章？有没有一个时刻，这个话题让你感到兴奋或触动？找回那个时刻。

**针对"题目本身没意思"：**
找到文章中你真正感兴趣的那一个点——不是整篇，而是某个细节、某个问题、某个你自己也不确定答案的地方。从那里重新出发。

**针对"感觉说不清"：**
承认不确定性，把它变成文章的一部分——"我也不完全确定，但我觉得……"有时候，诚实地写出困惑比假装全知更有力量。

**针对"感觉写不好"：**
切换模式：给自己写，而不是给读者写。把下一段写成只给自己看的草稿，不管文笔，只管把意思说出来。

**针对"疲惫"：**
停下来休息，不是放弃。规定一个回来的时间节点（明天上午10点），然后完全放下。

### 第三步：提供具体的重启动作

给出一个"5分钟可以做到"的具体重启动作，降低重新开始的门槛。

### 第四步：输出结果

```
【写作动力重燃】
诊断：[动力流失的主要原因]

重燃策略：[针对这个原因的策略]

立刻可以做的一件事：
[具体、可操作、5分钟内能完成的重启动作]

追问：[帮助作者找回写作初心的一个问题]
```

## Usage

描述你失去写作兴趣时的具体感受（什么时候开始没兴趣？是觉得无聊、困难还是沮丧？），并提供已写内容。

## Examples

### 示例 1：目的感丢失

**输入：**
> 我在写一篇关于城市绿化的文章，写了大概2000字，突然不知道自己为什么要写这篇文章，感觉没什么意义

**输出：**
```
【写作动力重燃】
诊断：目的感丢失——写作过程中陷入了"如何写好"的执行层，忘记了"为什么写"这个初始动力

重燃策略：
回到原点：想一想你最初为什么想写城市绿化这个话题？是某次走在树下的感受？是看到某个报道？是觉得这件事被忽视了？那个触发你写这篇文章的时刻，就是这篇文章真正的起点，也是它存在的意义。

立刻可以做的一件事：
打开一个新文档，用3-5句话写："我想写这篇文章，是因为……" 不要考虑文采，就是说出来。写完之后，看看有没有一句话可以成为文章的核心句，作为重新启动的锚点。

追问：有没有某一个关于城市绿化的时刻或画面，是你希望读者读完这篇文章之后也能理解的？
```

### 示例 2：感觉说不清

**输入：**
> 我在写关于"算法推荐是好是坏"的文章，写着写着发现这个问题太复杂了，感觉没有能力写清楚，不想继续了

**输出：**
```
【写作动力重燃】
诊断：知识边界焦虑——话题比预期复杂，对自己能否写好产生了怀疑，导致行动停滞

重燃策略：
降低标准，改变定位：你不需要写一篇解决"算法推荐是好是坏"这个问题的文章。你只需要写一篇"我在思考算法推荐这件事时注意到的一些问题"。这个定位的转变，让你从"专家"变成"思考者"——后者其实更容易写，也更真实。

立刻可以做的一件事：
回到已写的内容，找出你最有感觉、最确定的那一个点（哪怕只有一两句话）。把整篇文章的重心缩小到只围绕这一个点，其他的都暂时放弃。写一个更小的问题，比写一个你没把握回答的大问题要好得多。

追问：关于算法推荐，有没有一个你自己亲身经历过的时刻，让你觉得"这件事很重要"或"这件事有问题"？
```

## Best Practices

- 不鼓励"强迫自己写"——失去动力的写作通常质量很低，找回动力再写效率更高。
- 具体的重启动作要真正"小"——5分钟内能完成，而不是"想清楚你的目的"这种抽象建议。
- 有时候失去动力是因为文章方向确实有问题，不要把结构性问题归结为情绪问题。

## Edge Cases

- **作者说"就是懒，没别的原因"**：接受这个诊断，提供降低启动门槛的最小行动（"只写一句话"）。
- **文章是有截止日期的任务**：策略调整为"如何在有限时间内完成"而非"如何重燃热情"，优先推进可以快速完成的部分。
- **作者完全失去写这篇文章的理由**：坦诚建议考虑放弃这个选题，重新开始一个自己真正想写的话题。
