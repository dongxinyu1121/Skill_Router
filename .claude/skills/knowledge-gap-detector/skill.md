# 知识边界检测

本技能解决"写到某处，发现自己不够了解这个话题"的信息取舍类卡壳。知识边界卡壳有两种处理方式：补充知识后继续，或者调整写作角度绕过知识边界。本技能帮助作者判断应该选哪种。

## Workflow

### 第一步：识别知识缺口的性质

| 缺口类型 | 说明 | 处理倾向 |
|---------|------|---------|
| 核心缺口 | 缺少的知识是论点的直接支撑，没有它论点站不住 | 必须补充 |
| 辅助缺口 | 缺少的知识是支撑性细节，没有可以换其他方式 | 可以补充，也可以绕过 |
| 深度缺口 | 现有理解是对的，但不够深入精准 | 适度补充即可 |
| 误解缺口 | 之前的理解是错的，需要纠正 | 必须处理，否则文章会有错误 |

### 第二步：评估补充的成本与收益

问自己：
- 补充这个知识大概需要多长时间？
- 补充后的内容对文章的改善有多大？
- 有没有更简单的替代方式（换一个例子、缩小论述范围）？

### 第三步：提供处理策略

**策略A：补充学习（适用于核心缺口）**
- 指出需要学习的具体方向
- 建议最快速的学习途径（不要过度研究）
- 设定"够用就好"的学习目标

**策略B：调整写作角度绕过缺口（适用于辅助缺口）**
- 修改论述角度，只说自己确定的部分
- 用"据研究显示……（待查）"先占位，后补
- 换一个同样支撑论点但更熟悉的例子

**策略C：诚实承认局限（适用于深度缺口）**
- 在文中说明"本文基于……角度讨论，不涵盖……"
- 不要假装了解自己不了解的，读者能感觉到

**策略D：修正后继续（适用于误解缺口）**
- 先将错误理解的内容标注出来
- 搜索核实后修正，再继续

### 第四步：输出结果

```
【知识缺口诊断】
缺口位置：[在哪里发现知识不足]
缺口内容：[具体缺少什么知识]
缺口类型：[核心/辅助/深度/误解]

影响评估：
　对论点的影响：[这个缺口会不会让论点站不住]
　补充成本：[大概需要多少时间/精力]

推荐策略：[策略A/B/C/D]
具体操作：[按照推荐策略，接下来做什么]

如选择绕过缺口：[具体的绕过方式，换什么角度]
如选择补充学习：[具体学习方向，建议查阅什么类型的资料]
```

## Usage

描述你在哪里卡住、发现了什么知识不足，以及这个知识对你的论点有多重要。

## Examples

### 示例 1：核心缺口，需要补充

**输入：**
> 文章论点：政府应该为新能源汽车提供更多补贴
> 卡壳：我想引用具体的补贴效果数据，但不确定目前中国新能源补贴政策的具体数字和效果

**输出：**
```
【知识缺口诊断】
缺口位置：论证"政府补贴有效"的部分
缺口内容：中国新能源汽车补贴政策的具体数额、执行情况和效果数据
缺口类型：核心缺口（补贴效果是论证政府应该增加补贴的直接依据）

影响评估：
　对论点的影响：较大——没有数据支撑，"补贴有效"只是主张，无法说服读者
　补充成本：低——这类政策数据公开易得，1-2小时内可以找到

推荐策略：策略A（补充学习）
具体操作：
1. 搜索"新能源汽车补贴政策 2022-2024 效果"
2. 查阅工信部或国务院发布的政策文件，找销量数据与补贴政策的时间关联
3. 目标：找到1-2个具体数字（如"补贴期间销量增长X%"或"每辆车补贴X元"）即可，不需要深入研究补贴机制细节
4. 找到后填入论证，继续写作

如选择补充学习：查阅中国政府网、工信部官网、或"中国新能源汽车补贴退坡"相关报道
```

### 示例 2：辅助缺口，可以绕过

**输入：**
> 文章是散文，写咖啡文化
> 卡壳：我想说"咖啡是从埃塞俄比亚传到阿拉伯再到欧洲的"，但不确定这个历史传播路径是否完全准确

**输出：**
```
【知识缺口诊断】
缺口位置：关于咖啡历史起源的描述
缺口内容：咖啡的确切传播路径和时间节点
缺口类型：辅助缺口（这是背景信息，不是文章核心论点的直接支撑）

影响评估：
　对论点的影响：小——这只是为咖啡文化提供历史背景，不是核心论证
　补充成本：中——历史细节需要查阅可靠来源核实，可能需要一些时间

推荐策略：策略B（调整角度绕过缺口）
具体操作：
有两种绕过方式：

方式1（模糊化处理）：
将"咖啡从埃塞俄比亚传到阿拉伯再到欧洲"改为"咖啡起源于非洲，在向世界传播的过程中……"——说你确定的部分（非洲起源），省略你不确定的细节（具体路径）

方式2（换角度）：
不写传播历史，改写咖啡在某个具体地方的文化意义——你对某个城市或某种咖啡文化更了解的话，从那里写起

如选择绕过缺口：推荐方式1，一句话修改即可，不影响文章整体
```

## Best Practices

- 不是所有知识缺口都需要填补——辅助缺口通常可以绕过，不要因为一个支撑性细节不确定而停止写作。
- 核心缺口不能靠"感觉"或"印象"写，否则文章会有事实错误，损害可信度。
- "够用就好"的学习原则：只需要找到支撑你那个具体论点的信息，不需要成为这个领域的专家。

## Edge Cases

- **作者完全不了解某个话题但还是想写**：建议换一个自己更熟悉的角度或话题，不建议在几乎没有基础的领域写说理性文章。
- **缺口是专业技术知识**：评估读者是否需要这个精度的准确性；如果是大众读者，近似正确的通俗解释通常已足够。
- **多处都有知识缺口**：逐一评估，按核心/辅助分类，优先处理核心缺口，辅助缺口能绕就绕。
