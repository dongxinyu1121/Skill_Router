# 人物行为解锁

本技能解决小说、剧本等虚构写作中"人物行为不合理"或"不知道这个角色接下来会做什么"的卡壳。通过梳理人物的性格设定与行为逻辑，帮助作者找到符合人物本质的推进方向。

## Workflow

### 第一步：建立人物性格档案

从已写内容中提取：
- **外部特征**：职业、年龄、社会背景
- **性格核心**：2-3个最鲜明的性格特征
- **核心欲望**：这个人物最想要什么
- **核心恐惧**：这个人物最害怕什么
- **行为模式**：面对压力/选择时，这个人通常怎么反应

### 第二步：诊断行为失真的原因

| 原因 | 表现 |
|------|------|
| 情节需要反客为主 | 为了推进故事，让人物做了"不像他"的事 |
| 性格设定不清晰 | 一开始就没想清楚这个人是什么人 |
| 人物在成长但没有写出来 | 人物应该已经发生了变化，但没有铺垫 |
| 作者和人物混淆 | 让人物做了作者自己会做的事，而不是人物会做的事 |

### 第三步：提供符合人物性格的推进方向

给出 2-3 个方向，每个方向说明：
- 这个人物在当前处境下会怎么做
- 这个行为来自人物哪个性格特征
- 这个方向如何推进故事

### 第四步：输出结果

```
【人物行为分析】
人物性格档案：
　性格核心：[2-3个关键词]
　核心欲望：[这个人物最想要什么]
　核心恐惧：[这个人物最害怕什么]
　行为模式：[面对压力时通常怎么做]

当前处境：[人物现在面临什么]
卡壳原因：[为什么行为说不通或不知道怎么写]

方向 A（符合[哪个性格特征]）：
　行为：[这个人物会怎么做]
　依据：[为什么这个行为符合他的性格]
　故事推进：[这个行为会带来什么后果]

方向 B（符合[哪个性格特征]）：
　行为：[这个人物会怎么做]
　依据：[为什么这个行为符合他的性格]
　故事推进：[这个行为会带来什么后果]

方向 C（可选）：...

注意：[如果已写行为与性格矛盾，指出矛盾并建议处理方式]
```

## Usage

描述人物的基本性格设定，以及当前让你卡壳的情节情境。如已写内容中有人物行为描写，一并提供。

## Examples

### 示例 1：不知道人物会做什么

**输入：**
> 人物：陈明，40岁，工厂主管，外表沉默寡言，内心对家人极度保护，因为小时候看着父亲被人欺负而无力反抗，发誓绝不让家人受委屈
> 当前情节：他发现同事在背后说他儿子的坏话，不知道他会怎么反应

**输出：**
```
【人物行为分析】
人物性格档案：
　性格核心：沉默、保护欲强、内心有创伤
　核心欲望：保护家人不受委屈
　核心恐惧：重演父亲的无力感（家人被欺负而自己无法保护）
　行为模式：平时克制，但一旦触及家人，会有强烈反应；可能以沉默积累压力，爆发时超出预期

当前处境：发现同事在背后说儿子坏话

方向 A（保护欲 + 沉默积累）：
　行为：陈明没有立刻发作，沉默离开现场，但之后开始想办法——可能是收集同事的把柄、暗地里给同事穿小鞋
　依据：符合他"沉默积累"的行为模式，保护家人的欲望会推动他行动，但不是正面冲突
　故事推进：暗战升级，制造持续紧张感

方向 B（触及底线，罕见的正面爆发）：
　行为：陈明当场转身，走到同事面前，没有大声，但用一种让人不寒而栗的语气说出警告
　依据：触及了他的核心恐惧（家人受委屈），有时候最沉默的人爆发时反而最有压迫感
　故事推进：建立陈明的"不可冒犯"的人物形象，影响后续其他人对他的态度

注意：无
```

### 示例 2：行为与性格矛盾

**输入：**
> 人物：李雪，22岁大学生，独立、倔强，从来不求人
> 已写内容：李雪突然主动向一直讨厌的同学借钱，并感谢了他很多次

**输出：**
```
【人物行为分析】
人物性格档案：
　性格核心：独立、倔强、不服输
　核心欲望：自主，不依赖任何人
　核心恐惧：被人看不起、失去主动权
　行为模式：遇到困难优先自己解决，实在不行宁可走弯路也不轻易求人

当前处境：主动向讨厌的同学借钱并多次道谢

卡壳原因：这个行为与李雪的核心性格直接冲突——一个倔强独立的人不会轻易向讨厌的人低头，更不会多次道谢

方向 A（修改前情，增加铺垫）：
　建议：在这个场景之前，必须有足够的"逼迫性"——她为什么非得找这个人借？她是不是已经试过了所有其他途径？越是独立的人，低头的代价越大，也需要越强的理由
　具体：补写李雪被逼到走投无路的过程，让读者理解为什么她必须这样做

方向 B（修改行为本身，让行为更符合性格）：
　建议：她可以借钱，但态度不会是"感谢了很多次"——她的方式可能是非常简短的一句"我需要借点钱"，拿到钱之后说一声"等我还"，然后转身就走，全程保持一种尊严感
　效果：同样完成了"借钱"这个情节需要，但行为方式符合她的性格

注意：已写的"多次道谢"与人物设定矛盾较大，建议重写这段——不是不能让她借钱，而是她的方式不应该是"感激涕零"
```

## Best Practices

- 不能因为情节需要就让人物"不像自己"，如果情节需要人物做某件事，必须找到符合人物动机的理由。
- 人物的成长是可以的，但需要铺垫——人物不能在没有经历任何变化的情况下突然变成另一个人。
- 不替作者决定选哪个方向；当两个方向都合理时，选择权在作者。

## Edge Cases

- **人物性格本来就模糊**：先帮助作者确定这个人物的2-3个核心性格特征，再讨论行为。
- **作者想写人物的"意外之举"**：意外之举也需要有根植于性格深处的理由，帮助找到那个理由，让"意外"变得"合理"。
- **人物是反派或复杂道德角色**：同样的逻辑适用，行为必须来自人物自己的逻辑，而不是"他是坏人所以他会做坏事"。
