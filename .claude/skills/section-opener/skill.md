# 段落破题

本技能解决"知道这段要写什么，但不知道第一句话怎么写"的开头类卡壳。每写一段新内容，都需要一个入口。本技能帮助找到那个入口。

## Workflow

### 第一步：理解这段的写作目标

明确：
- 这段话的核心内容是什么（要论述的论点、要描写的场景、要展开的话题）
- 这段在文章整体结构中的位置（承接上文什么，引出下文什么）
- 期望读者读完这段之后有什么感受或理解

### 第二步：分析最适合的开头策略

| 策略 | 说明 | 适合场景 |
|------|------|---------|
| 直接陈述 | 开门见山说出段落主张 | 议论文分论点、报告各部分 |
| 场景引入 | 从一个具体画面进入 | 散文、叙事类写作 |
| 问题引入 | 用一个问句吸引读者思考 | 说理文、引发读者参与 |
| 对比引入 | 先说反面，再转入正题 | 需要强调差异或转折的内容 |
| 时间/地点定位 | 用时间或地点锚定场景 | 叙事类、散文 |
| 数据引入 | 用令人意外的数字开场 | 议论文、新闻类 |
| 承接上文 | 从上段结尾自然延伸 | 需要紧密衔接的段落 |

### 第三步：提供多个开头选项

给出 3 种不同策略的开头句，每种附：
- 策略名称
- 开头句（20字以内）
- 适合使用的理由

### 第四步：输出结果

```
【段落破题建议】
这段的核心内容：[一句话说明]
在文章中的位置：[承接什么，引出什么]

开头选项：

选项 A（[策略]）：
"[开头句]"
适合原因：[一句话]

选项 B（[策略]）：
"[开头句]"
适合原因：[一句话]

选项 C（[策略]）：
"[开头句]"
适合原因：[一句话]

推荐：选项 [X]，因为[一句话]
```

## Usage

提供上文最后 1-2 句话，以及这一段要写的核心内容。

## Examples

### 示例 1：议论文分论点段落

**输入：**
> 上文结尾：…由此可见，阅读习惯对学业成绩有显著正向影响。
> 这段要写：第二个论点——阅读对情绪管理能力也有帮助

**输出：**
```
【段落破题建议】
这段的核心内容：阅读对情绪管理能力的积极影响
在文章中的位置：承接上段（阅读对成绩的影响），展开第二个维度（情绪管理）

开头选项：

选项 A（直接陈述）：
"阅读带来的益处不止于学业。"
适合原因：简洁过渡，直接拓展论证维度，衔接自然

选项 B（数据引入）：
"研究发现，每天阅读30分钟的青少年，情绪调节能力高出同龄人23%。"
适合原因：用数字直接建立新论点的可信度，不需要过渡铺垫

选项 C（问题引入）：
"除了成绩，阅读还能带来什么？"
适合原因：用问句制造段落间的节奏停顿，引导读者带着问题读下去

推荐：选项 A，因为前文已经用过数据，此处换一种节奏（简洁过渡）可以调整全文的读感
```

### 示例 2：散文新场景切入

**输入：**
> 上文结尾：…那个夏天就这么结束了。
> 这段要写：两年后再回到那个地方，发现一切都变了

**输出：**
```
【段落破题建议】
这段的核心内容：两年后重返旧地，物是人非的感受
在文章中的位置：时间跳跃，从过去切到"现在"，情绪从温暖转向惆怅

开头选项：

选项 A（时间定位）：
"两年后，我又去了那里。"
适合原因：简洁的时间跳跃，读者立刻知道视角切换了，不需要解释

选项 B（场景引入，先写变化）：
"那家面馆不见了。"
适合原因：从一个具体的细节变化切入，比直接说"一切都变了"更有冲击力

选项 C（感受引入）：
"我本来以为自己准备好了。"
适合原因：先说内心预期，再展开和现实的落差，制造悬念

推荐：选项 B，因为散文的力量在于具体细节，"那家面馆不见了"比"两年后我又去了那里"有更强的情感载重量
```

## Best Practices

- 开头句不必精彩，但必须准确——它的功能是"打开这段话的门"，不是表演文采。
- 议论文段落开头优先直接，散文段落开头优先具体；不要混淆两种文体的策略。
- 如果三种选项都感觉不对，可能是这段话的内容本身需要重新想清楚，建议先用 `outline-expander` 或 `angle-finder`。

## Edge Cases

- **不知道这段要写什么内容**：本技能无法使用，先用 `outline-expander` 确认段落主题。
- **开头要求特别有吸引力（如标题或引言）**：参考 `hook-strengthener`，那个技能专门处理吸引力问题。
- **段落在文章开头（全文第一段）**：全文开头的策略有所不同，使用 `hook-strengthener`。
