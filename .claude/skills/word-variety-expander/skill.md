# 用词多样化

本技能解决"总是用同样的词，文章读起来单调"的语言类卡壳。通过分析重复用词的模式，提供在语义准确的前提下更丰富的表达选择。

## Workflow

### 第一步：识别重复用词模式

扫描已写内容，识别：
- **高频重复词**：同一个词在短篇幅内出现超过3次
- **万能词依赖**：过度依赖"很""非常""好""重要""明显"等无信息量的词
- **动词贫乏**：大量使用"是""有""做""说"等弱动词
- **形容词单调**：形容任何事物都用同几个词

### 第二步：分析重复的原因

| 原因 | 说明 |
|------|------|
| 词汇量局限 | 不知道有其他更准确的词 |
| 求稳心理 | 知道有其他词，但不确定用法是否正确 |
| 思维固化 | 某个词和某个概念绑定得太紧，想不到替换 |
| 语言习惯 | 某些词是作者自身的口头禅 |

### 第三步：提供替换建议

对每个识别出的重复词，提供：
- **精确替换**：意思相近但更准确的词
- **风格替换**：根据语境选择更文学/更口语/更正式的同义词
- **结构替换**：有时候换一种句式比换一个词更有效

重要原则：替换词必须和原词语义相近，且适合上下文语气。不能为了多样性而用错词。

### 第四步：输出结果

```
【用词多样化建议】
发现的问题：
　高频重复词：[列出出现超过3次的词及出现次数]
　万能词：[列出过度使用的无信息量词]
　弱动词：[列出主要的弱动词]

替换建议：

[重复词1]（出现X次）
　精确替换：[词1]（适用于[什么语境]）/ [词2]（适用于[什么语境]）
　文学化：[词] / 正式化：[词] / 口语化：[词]
　示例：原句"[句子]"→ 替换后"[句子]"

[重复词2]...

总体建议：[2-3条针对这篇文章用词风格的整体建议]
```

## Usage

提供需要改善的已写内容，本技能自动识别重复用词并提供替换方案。

## Examples

### 示例 1：高频重复词和弱动词

**输入片段：**
> 这本书很好，写得很好，作者的观点也很好。书里面有很多故事，这些故事都很真实。我觉得这本书对读者很有帮助。

**输出：**
```
【用词多样化建议】
发现的问题：
　高频重复词："很好"（3次）、"书"（3次）、"故事"（2次）、"很"（5次）
　万能词：大量"很好""很真实""很有帮助"——这些词几乎没有信息量
　弱动词：主要用"是""有""觉得"，没有动态感

替换建议：

"很好"（3次）
　精确替换：精彩、出色、扎实、有力、细腻（根据具体说的是哪方面）
　示例：
　- "写得很好" → "叙事节奏拿捏得恰到好处"（具体化）
　- "观点也很好" → "观点犀利且有说服力"（精确化）
　- "这本书很好" → "这本书值得反复读"（用效果代替评价）

"很"（万能副词，5次）
　策略：删掉或替换为更精确的程度词
　- "很真实" → "读起来像是真实经历的" 或 删掉"很"直接用"真实"
　- "很有帮助" → "对读者有切实的参考价值"

弱动词"有"
　示例："有很多故事" → "穿插了大量真实故事" 或 "以故事为主要叙述方式"

总体建议：
1. 评价文章质量时，说具体是哪方面好，而不是泛泛说"好"
2. 用效果和感受代替空洞形容词（"读完想立刻实践"比"很有帮助"有力量）
3. 动词是句子的引擎，尽量找更有画面感的动词替换"有""是"
```

### 示例 2：情绪形容词单调

**输入片段：**
> 她感到很难过。看着窗外，她依然很难过。想起那件事，她还是很难过。

**输出：**
```
【用词多样化建议】
发现的问题：
　高频重复词："很难过"（3次）、"她"（3次）
　问题：三句话说了同一件事，而且用词完全相同，没有任何情感的层次变化

"难过"的情感层次替换：
　轻度：不是滋味、有些沉闷、心里空了一块
　中度：难受、心疼、有点喘不过气
　重度：心里像压着什么、悲从中来、像被什么东西攥住了
　特定状态：茫然、麻木（不是难过本身，是难过过度后的状态）

改写示例：
　原：她感到很难过。看着窗外，她依然很难过。想起那件事，她还是很难过。

　改写：她感到难受。看着窗外，说不清是因为光线太暗还是别的什么，只是有点透不过气。想起那件事，她闭上眼睛，胸口像是被人攥了一下。

改写说明：三句话用了三种不同的方式表达悲伤，而且有层次递进感——从"难受"到"透不过气"到"被攥住"，情绪在加深
```

## Best Practices

- 替换词必须在语义上准确，不能为了多样性而用错词——"悲伤"和"悲壮"不是同一个意思。
- 有时候最好的替换不是换词，而是改变表达方式（如用具体行为代替情绪词）。
- 不需要把所有重复词都替换——战略性地重复某个词有时候是一种修辞手法；问自己"这个重复是有意为之还是无意的"。

## Edge Cases

- **作者使用某个词是刻意的风格选择**：确认是否为有意重复，如果是，则跳过该词不建议替换。
- **文章中文英混用**：对中文部分进行分析，英文部分不做替换建议。
- **专业文章有固定术语**：专业术语不建议替换，因为换了词可能改变专业含义。
