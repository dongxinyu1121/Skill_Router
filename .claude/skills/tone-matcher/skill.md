# 语气一致性

本技能解决写作过程中语气或风格发生偏移的问题。当作者感觉"读起来不像同一个人写的"，本技能帮助识别偏移位置，分析原因，并提供修正方向和示例。

## Workflow

### 第一步：建立原有语气基准

阅读文章前段（偏移前的内容），从五个维度提取语气基准：

| 维度 | 评估项 |
|------|------|
| 正式程度 | 书面 / 偏书面 / 口语 / 偏口语 |
| 情感温度 | 冷静克制 / 温和平缓 / 热情饱满 / 激烈犀利 |
| 句式风格 | 长句铺陈 / 短句有力 / 长短交替 / 问答交替 |
| 人称距离 | 第一人称亲近 / 第二人称对话感 / 第三人称客观 |
| 词汇倾向 | 雅词典故 / 日常白话 / 专业术语 / 网络用语 |

### 第二步：对比分析偏移段落

将"变味"段落与基准对比，逐维度检查：

- 哪个维度发生了变化？
- 变化程度：轻微偏移 / 明显偏移 / 完全不同
- 可能的原因：切换话题时不自觉用了不同风格？参考了其他材料？情绪状态变化？

### 第三步：提供修正建议

给出具体的修正方向，并将偏移段落中 1-2 个典型句子进行改写示范。

### 第四步：输出结果

```
【语气一致性分析】
原有语气基准：
　正式程度：[等级]
　情感温度：[等级]
　句式风格：[描述]
　词汇倾向：[描述]

偏移位置：[从哪句/哪段开始变化]
偏移维度：[哪个维度发生了变化]
偏移原因：[可能的原因，一句话]

修正方向：[具体怎么调整]

改写示例：
　原句："[偏移的句子]"
　调整为："[符合原有语气的版本]"

　原句："[另一个例子]"（可选）
　调整为："[符合原有语气的版本]"
```

## Usage

提供已写的全部内容（至少包含偏移前的部分和偏移的段落），以及作者感觉"变味了"的段落位置。如有目标语气的描述，一并提供。

## Examples

### 示例 1：由正式转为口语

**输入：**
> 前段（基准）：
> 城市化进程的加速，使得传统社区结构面临深刻的解体压力。邻里之间的陌生化并非偶然现象，而是现代性带来的必然代价。
>
> 偏移段落：
> 说真的，现在的人都太忙了，哪有时间认识邻居啊。我昨天还想说，楼上的那个人住了三年我都不知道叫什么名字，这也太离谱了吧。

**输出：**
```
【语气一致性分析】
原有语气基准：
　正式程度：书面
　情感温度：冷静克制
　句式风格：长句铺陈
　词汇倾向：偏书面（"城市化进程""解体压力""现代性"）

偏移位置：第二段开头"说真的"起
偏移维度：正式程度（书面→口语）、情感温度（克制→随意）、词汇倾向（书面→网络口语）
偏移原因：从宏观论述切入个人例子时，不自觉采用了日常说话方式

修正方向：保留"个人经历"这个素材，但用书面语重新表述，去掉"说真的""太离谱了吧"等口语标记

改写示例：
　原句："说真的，现在的人都太忙了，哪有时间认识邻居啊。"
　调整为："现代都市人的时间被工作与通勤切割殆尽，与邻居建立关系已成奢望。"

　原句："楼上的那个人住了三年我都不知道叫什么名字，这也太离谱了吧。"
　调整为："笔者所在楼栋，同一楼层的住户在三年间始终形同陌路，互不知名。"
```

### 示例 2：情感温度突然升高

**输入：**
> 前段（基准）：
> 阅读习惯的培养需要从小开始，家庭环境和学校教育都发挥着重要作用。
>
> 偏移段落：
> 我真的非常非常热爱阅读！每次拿起一本好书，整个世界都变得美好了！这种感觉真的太棒了！！

**输出：**
```
【语气一致性分析】
原有语气基准：
　正式程度：偏书面
　情感温度：温和平缓
　句式风格：陈述句为主，节奏稳健
　词汇倾向：日常书面，不夸张

偏移位置："我真的非常非常热爱阅读"起
偏移维度：情感温度（平缓→过于激动）、标点使用（叹号堆积）
偏移原因：从客观陈述切到个人感受时，情绪没有经过节制

修正方向：保留个人热爱阅读的内容，去掉叠加的副词和连续叹号，用具体描述代替情绪宣泄

改写示例：
　原句："每次拿起一本好书，整个世界都变得美好了！"
　调整为："每次拿起一本值得读的书，其他事情似乎都暂时退到了背景里。"
```

## Best Practices

- 语气分析要基于文章前段，而非作者描述的"目标语气"——有时作者描述的和实际写的并不一致，以文字为准。
- 改写示例要尽量保留原句的意思，只调整语气，不替作者重写内容。
- 轻微的语气变化有时是好事（增加节奏变化），要区分"有意为之的变化"和"不自觉的偏移"。

## Edge Cases

- **全文语气本来就不统一**：无法建立基准，建议作者先明确想要的整体风格，再重新审视全文。
- **作者有意在同一篇文章中使用两种语气**：告知本技能只适用于无意偏移的情况，有意的语气切换不需要"修正"。
- **偏移段落只有一两句话**：可以直接给出改写版本，不需要详细分析。
