# 找回自己的声音

本技能解决写作风格模板化、缺乏个性的问题。当作者感觉自己写的东西"像教科书""像别人写的""太普通了"，本技能帮助找出个人风格特征并将其放大。

## Workflow

### 第一步：诊断"没有个性"的具体原因

阅读作者认为"不像自己"的段落，判断原因：

| 原因 | 表现 | 根本问题 |
|------|------|---------|
| 模仿模板 | 大量使用"首先…其次…最后…""由此可见…" | 用结构代替了思考 |
| 压制真实感受 | 说的是"客观道理"，自己真正的看法藏着没说 | 怕说错所以不说真话 |
| 用词过度通用 | "很好""很重要""很有价值" | 没有找到准确的词 |
| 叙述失去温度 | 叙述事件，但情绪是旁观的，不是经历者的 | 和写作对象保持了过多距离 |
| 句式过于规整 | 每句话长度相近，节奏单调 | 没有让语言跟着情感走 |

### 第二步：提取个人风格特征（如有参考文字）

如果作者提供了自己满意的旧文，提取其中的风格特征：

- **标志性词汇或表达**：作者惯用的词、比喻、句式
- **情感处理方式**：直接表达 / 用细节暗示 / 用反语
- **节奏特征**：长句收放 / 短句堆叠 / 问句节奏

### 第三步：提供"找回声音"的具体建议

给出 3 条操作性建议，帮助作者打破模板状态：

- **释放真实感受**：鼓励作者说出自己真正的看法
- **找到精准的词**：用具体替换模糊
- **打破句式惯性**：用不同长度和结构的句子

### 第四步：输出结果

```
【找回声音建议】
当前问题：[为什么读起来没有个性，一句话]
个人风格特征：[如有参考文字则列出；否则填"待建立"]

建议 1：[具体操作]
建议 2：[具体操作]
建议 3：[具体操作]

改写示例：
　原句："[模板化的句子]"
　找回声音："[更有个性的版本]"

追问：[帮助作者想清楚自己真正的感受或观点的一个问题]
```

## Usage

提供作者认为"没有自己味道"的段落。如有以前写过且自己满意的文字片段，一并提供作为风格参考。

## Examples

### 示例 1：议论文过度模板化

**输入：**
> 问题段落：
> 阅读是非常重要的。首先，阅读可以增长知识。其次，阅读可以开阔眼界。最后，阅读可以提升个人修养。由此可见，我们应该养成良好的阅读习惯。

**输出：**
```
【找回声音建议】
当前问题：文章完全依赖"首先/其次/最后"的结构支架，所有观点都是套话，没有任何属于这个作者的真实看法
个人风格特征：待建立（无参考文字）

建议 1：说出你真正的看法，而不是"正确答案"
　你认为阅读最重要的是哪一点？不是教科书上说的，是你自己读书读到现在真正体会到的那一点。把那句话写出来。

建议 2：用具体代替抽象
　"增长知识"太空洞。你从哪本书里学到了什么具体的东西？那件事怎么影响了你？把那个具体的故事写进去。

建议 3：打破"首先/其次/最后"的结构
　不是不能有结构，而是结构不应该暴露在外面。试试把三点中最想说的那一点展开，其余两点融进去或者删掉。

改写示例：
　原句："首先，阅读可以增长知识。"
　找回声音："我大概是在读完《人类简史》之后，第一次觉得'增长知识'这个词太小了——阅读给你的不只是知识，是一种和历史上所有思考过这些问题的人同步的感觉。"

追问：你读过哪本书，让你觉得"幸好读了这本"？从那本书里找你真正的观点。
```

### 示例 2：散文叙述失去温度

**输入：**
> 问题段落：
> 那次旅行给我留下了很深的印象。我们去了很多地方，看了很多风景，吃了很多当地的食物。整体体验非常好，让我觉得很放松。

**输出：**
```
【找回声音建议】
当前问题：叙述像流水账，情感词汇全是"很深""非常好""很放松"等无信息量的形容词，作者是旁观者而不是经历者
个人风格特征：待建立（无参考文字）

建议 1：找到那次旅行中最真实的一个细节
　不要试图概括整趟旅行。找那一刻：一个你现在还记得的画面、气味、或者一句别人说的话。从那里开始写。

建议 2：把"感受词"换成"感受本身"
　不要说"很放松"，写出放松的样子：你当时在做什么，想什么，还是什么都没想？

建议 3：允许自己说"负面的"或"复杂的"感受
　旅途中有没有什么让你烦恼、失望、或者意外的事？那些才是让文章真实的部分。

改写示例：
　原句："看了很多风景，吃了很多当地的食物，整体体验非常好。"
　找回声音："那天在山顶上等了两小时，云一直没散。后来我们下山去吃了一碗面，老板娘说这里冬天每天都是雾，问我们为什么这个季节来。我当时说不上来。"

追问：那次旅行中，有没有一个让你现在想起来还有感觉的瞬间——哪怕很小的一件事？
```

## Best Practices

- 找回"声音"的核心是说真话，而不是变得奇特或炫技；建议要引导作者靠近自己的真实感受。
- 改写示例要基于作者提供的内容，不能写成完全不同的内容——是在作者的素材上找声音，而不是替他重写。
- 对于初学写作的人，"没有个性"很正常，建议要有耐心，侧重具体操作而非风格评判。

## Edge Cases

- **作者没有提供参考文字**：无法提取个人风格特征，只能给出通用的"找回声音"建议，并在结果中说明。
- **作者误以为"写得像别人"就是"有风格"**：解释个人声音不等于模仿偶像，而是说自己真正想说的话。
- **文章有格式要求（如命题作文）**：在格式约束内找声音，重点放在"你真正的观点"而非突破格式。
