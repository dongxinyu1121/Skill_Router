# 情节解锁

本技能专用于小说、剧本、故事等虚构叙事的情节卡壳。当作者写到一半，情节不知道怎么推进，人物不知道该做什么，本技能帮助分析当前故事状态，提供有张力的续写方向。

## Workflow

### 第一步：建立故事状态图

阅读已写内容，提取：

- **主要人物**及其当前处境、目标、内心状态
- **核心冲突**：是什么让故事产生张力（内部冲突 / 人物间冲突 / 人物与环境的冲突）
- **故事当前所处阶段**：参照经典三幕结构判断

```
三幕结构参考：
第一幕（建置）：介绍人物、世界、触发事件
第二幕（对抗）：主角追求目标，不断遭遇阻碍（占全篇约60%）
第三幕（结局）：冲突最终解决，人物完成或失败
```

### 第二步：诊断情节卡壳原因

| 卡壳原因 | 表现 |
|---------|------|
| 动机不足 | 人物没有足够的理由去做接下来的事 |
| 冲突缺失 | 情节太平，人物之间没有真正的对立 |
| 节奏太慢 | 铺垫过多，读者（和作者）都失去耐心 |
| 情节悬空 | 前面埋的伏笔不知道怎么收 |
| 人物失控 | 人物的行为已经脱离了最初设定的性格 |
| 方向迷失 | 不知道这个故事最终要走向哪里 |

### 第三步：提供情节推进方向

给出 2-3 个方向，每个方向包含：
- **发生什么**：下一个情节事件的核心
- **对故事的影响**：推进冲突 / 揭示信息 / 改变人物关系
- **戏剧张力来源**：这个方向的看点在哪里

### 第四步：输出结果

```
【情节解锁结果】
当前故事状态：[人物处境 + 主要矛盾，3句以内]
故事阶段：[第一幕 / 第二幕前期 / 第二幕后期 / 第三幕]
卡壳原因：[诊断结果]

方向 A：[情节事件]
　对故事的影响：[推进/揭示/改变]
　戏剧张力：[看点所在]

方向 B：[情节事件]
　对故事的影响：[推进/揭示/改变]
　戏剧张力：[看点所在]

方向 C：[情节事件]（可选）
　对故事的影响：[推进/揭示/改变]
　戏剧张力：[看点所在]

追问：[如需更多信息才能给出好建议，提最关键的一个问题]
```

## Usage

提供已写内容或情节摘要，并注明主要人物、故事类型（悬疑/爱情/奇幻等）和预期结局（如有）。

## Examples

### 示例 1：第二幕冲突缺失

**输入：**
> 故事类型：现实主义小说
> 人物：林晓，30岁，刚辞职，想回家乡开餐馆
> 已写内容：林晓辞职了，告诉了家人，家人表示支持，她开始联系房源
> 卡壳描述：感觉太顺了，不知道怎么写下去

**输出：**
```
【情节解锁结果】
当前故事状态：林晓完成了"辞职决定"阶段，即将进入创业执行阶段，但目前没有任何阻碍
故事阶段：第二幕前期（对抗阶段刚开始）
卡壳原因：冲突缺失——主角的目标没有遭遇任何真实阻力，故事缺乏张力

方向 A：外部障碍——房源出问题
　对故事的影响：推进冲突，制造第一个真实障碍
　戏剧张力：看她如何应对意外，以及这个挫折是否动摇了她的决心

方向 B：人际冲突——支持背后有隐情
　对故事的影响：揭示信息，使"家人支持"这个前提变得复杂
　戏剧张力：父母说支持，但其实各有盘算——这个裂缝会怎么影响林晓

方向 C：内心冲突——突然收到前公司的橄榄枝
　对故事的影响：制造内部冲突，让主角的选择变得艰难
　戏剧张力：放弃的东西重新出现，她会不会动摇

追问：无
```

### 示例 2：伏笔不知道怎么收

**输入：**
> 故事类型：悬疑
> 已写内容：前面埋了一条线——主角在凶案现场发现了一只绿色的钢笔，但写了五章还没有用到它

**输出：**
```
【情节解锁结果】
当前故事状态：主线调查进行中，一个重要道具（绿色钢笔）悬置未用
故事阶段：第二幕
卡壳原因：情节悬空——前伏笔压力积累，作者不知道如何兑现

方向 A：钢笔是凶手留下的
　对故事的影响：揭示信息，将道具直接连接到核心谜题
　戏剧张力：揭示时机的选择——是主角主动发现，还是被动获知

方向 B：钢笔属于意外卷入的第三者
　对故事的影响：引入新人物，使调查方向出现转折
　戏剧张力：这个第三者的出现会让案件变得更复杂还是更清晰

方向 C：钢笔是主角认识的人的
　对故事的影响：制造主角的内心冲突——是否要继续查下去
　戏剧张力：最高，但需要前面有足够的情感铺垫

追问：主角和哪些配角有比较深的情感连接？（决定方向C是否可行）
```

## Best Practices

- 不替作者写正文，只提供情节构思方向。
- 所有方向必须与已有人物的性格设定一致，不能引入与前文矛盾的行为。
- 优先推荐能同时推进"外部事件"和"内部成长"的方向——好故事的情节必须影响人物。

## Edge Cases

- **只有人物没有情节**：要求作者先说明每个主要人物的目标和最大阻碍。
- **故事已进入结局阶段**：建议使用 `ending-designer`。
- **作者不确定结局**：先帮助确认故事的核心主题，再推演情节方向。
