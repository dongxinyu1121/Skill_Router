# 空白启动

本技能解决"脑子完全空白，什么都想不出来"的创意类卡壳。空白状态是写作中最令人沮丧的卡壳之一。本技能通过定向引导问题和低门槛的写作练习，帮助作者重新激活写作状态。

## Workflow

### 第一步：诊断空白的类型

| 空白类型 | 表现 | 本质 |
|---------|------|------|
| 话题空白 | 完全不知道写什么 | 选题未确定或太宽泛 |
| 素材空白 | 知道写什么，但脑子里没有内容 | 素材积累不足或提取不出来 |
| 启动空白 | 有想法，但就是无法开始写第一个字 | 启动阻力问题，不是内容问题 |
| 中途空白 | 写着写着突然头脑一片空白 | 疲惫或创意耗尽 |

### 第二步：匹配启动策略

**针对话题空白：**
用以下问题找到写作方向：
- 最近有什么事让你有强烈感受？（愤怒/感动/困惑/惊喜）
- 有没有什么话你一直想说但没有说？
- 有没有什么问题你一直在想但没有答案？

**针对素材空白：**
用自由联想法激活：
- 想到[话题]，第一个浮现的画面是什么？
- 和[话题]有关的，你亲眼见过的最具体的一件事是什么？
- 如果要向一个10岁的孩子解释[话题]，你会怎么说？

**针对启动空白：**
用最低门槛的方式开始：
- 写一个烂开头（明确允许自己先写垃圾）
- 写"我想写的是……"直到找到感觉
- 从文章中间开始写，不要从开头开始

**针对中途空白：**
停下来，做一件和写作无关的事（5分钟），然后回来只写一句话。

### 第三步：提供具体引导问题

根据作者的话题（如有），给出 5 个具体的引导性问题，帮助激活思路。

### 第四步：输出结果

```
【空白启动方案】
空白类型：[诊断结果]

立刻做的一件事：[最低门槛的启动动作]

引导问题（从这些问题的答案里找到写作起点）：
1. [问题]
2. [问题]
3. [问题]
4. [问题]
5. [问题]

启动练习：
[一个5分钟的写作练习，帮助作者进入写作状态]
```

## Usage

描述你现在的状态（完全没有想法，还是有话题但写不出来），以及文章的主题（如果有）。

## Examples

### 示例 1：话题空白

**输入：**
> 我需要写一篇文章，但完全不知道写什么，脑子里什么都没有

**输出：**
```
【空白启动方案】
空白类型：话题空白（选题未确定）

立刻做的一件事：
打开手机，翻一翻最近一周你截图保存过什么——截图这个动作说明当时有触动，那个触动可能就是文章的起点。

引导问题：
1. 最近一个月，有没有某件事让你忍不住想和别人说？是什么？
2. 有没有什么话你常常想说，但总是没找到合适的机会？
3. 最近有没有什么事让你生气，或者觉得"这不对"？
4. 有没有某个问题，你想了很久但还没有答案？
5. 有没有某个你觉得被低估或被误解的东西？（一个人、一件事、一种经历）

启动练习：
用10分钟，不停地写"我想说的是……"，不管写出来的东西好不好，就是不停地写这个句子的接续。写到某一句让你觉得"对，就是这个"，那就是你的写作起点。
```

### 示例 2：启动空白

**输入：**
> 我知道我要写什么，关于职场中的性别不平等，也有很多想法，但就是打不出第一个字，一直在盯着空白的屏幕

**输出：**
```
【空白启动方案】
空白类型：启动空白（有内容，但无法开始）

立刻做的一件事：
不要从开头写。现在打开文档，跳过开头，直接写你觉得最有话说的那一个点——哪怕只是一句话，哪怕很烂，哪怕不成段落。开头可以最后再写。

引导问题（帮助激活具体内容）：
1. 关于职场性别不平等，你亲眼见过或亲身经历过的最具体的一件事是什么？
2. 有没有某一刻，你觉得"这就是问题所在"，那是什么时候？
3. 你觉得大多数人关于这个话题最大的误解是什么？
4. 如果你只能对读者说一件事，你最想说的是哪一件？
5. 你希望读完这篇文章的人有什么改变？

启动练习：
设定5分钟计时器，用来回答上面的第1个问题——只写那件事，不用考虑它是不是开头，不用考虑文笔，就是把那件事写出来。计时器响了停下来，看看你写的。那可能就是这篇文章真正的核心素材。
```

## Best Practices

- 空白状态的本质是"门槛太高"——降低门槛比鼓励作者"努力想"更有效。
- 引导问题要具体，不要是"你有什么感想"这种开放到无从下手的问题。
- 启动练习要设定时间限制（5-10分钟），有截止感反而更容易开始。

## Edge Cases

- **作者对任何话题都没有感觉**：可能是疲惫或情绪问题，建议先休息，不强行写作。
- **强制命题，话题自己不感兴趣**：找命题话题和自己真实经历的交叉点，问"关于[命题]，我有没有任何亲身经历"。
- **已经写了一段时间，突然中途空白**：通常是创意疲劳，不是启动问题——建议休息5-10分钟，回来只写一句话，不要强迫自己"状态恢复"。
