# 结尾设计

本技能专门处理"内容写完了但不知道怎么收"的卡壳。通过理解文章的核心意图和情感基调，提供有力的结尾方案，避免虎头蛇尾或强行拔高。

## Workflow

### 第一步：提炼文章核心

阅读全文，提取：
- **核心主题**：文章最终要说的那件事
- **情感基调**：全文的情绪底色（沉静 / 激昂 / 温暖 / 悲伤 / 讽刺 / 思考）
- **文章类型**：决定结尾策略的边界条件

### 第二步：诊断结尾需要完成什么

| 文章类型 | 结尾的核心任务 |
|---------|-------------|
| 议论文 | 回扣论点，给出行动号召或深层意义 |
| 散文 | 完成情感或思想的落脚，留有余韵 |
| 小说/故事 | 解决冲突，或制造有意义的开放性结局 |
| 报告/说明文 | 总结要点，提出建议或展望 |

### 第三步：提供多种结尾方案

从以下策略中选取最适合的 2-3 种：

| 结尾策略 | 适合场景 | 效果 |
|---------|---------|------|
| 回扣开头 | 开头有意象或悬念的文章 | 形成闭环，结构感强 |
| 升华主题 | 议论文、说理性散文 | 从具体提炼出更大意义 |
| 情感收束 | 情感类散文 | 以感受收尾，留有余韵 |
| 开放式结尾 | 思考类文章、文学散文 | 引发读者自行延伸 |
| 行动号召 | 议论文、倡议类文章 | 推动读者行动 |
| 画龙点睛 | 任何类型 | 一句话点出全文灵魂 |
| 场景定格 | 散文、小说 | 以一个画面收束，有电影感 |

### 第四步：输出结果

```
【结尾设计方案】
文章核心：[一句话总结最想说的是什么]
情感基调：[全文的情绪底色]
结尾任务：[这篇文章的结尾需要完成什么]

方案 A（[策略名称]）：
[具体结尾文字，3-6句]

方案 B（[策略名称]）：
[具体结尾文字，3-6句]

方案 C（[策略名称]）：（可选）
[具体结尾文字，3-6句]

推荐：方案 [X]，原因：[一句话]
```

## Usage

提供全文内容（或摘要）和文章想传达的核心情感/观点。如当前已有结尾但感觉不好，一并提供并说明哪里感觉不对。

## Examples

### 示例 1：议论文结尾

**输入：**
> 文章核心：现代人应该主动减少手机使用时间，夺回被算法分割的注意力
> 情感基调：理性批判，带一点紧迫感
> 当前结尾："综上所述，我们应该减少手机使用，这对我们的生活有很大帮助。"（感觉太敷衍）

**输出：**
```
【结尾设计方案】
文章核心：注意力是这个时代最稀缺的资源，我们正在不知不觉地把它拱手相让
情感基调：理性批判，带紧迫感
结尾任务：从个人行为延伸到更深的意义，同时给读者留下一个行动冲动

方案 A（升华主题 + 行动号召）：
算法不会停止优化，手机不会主动合上。没有人会替你守住那些被切碎的小时。
把手机放下，不是一种节制，是一种夺回——夺回思考的时间，夺回感受的能力，夺回那个可以在一件事上停留超过三分钟的自己。

方案 B（画龙点睛）：
我们花了几十年学会如何使用工具，却忘了练习一件同样重要的事：放下它。

方案 C（开放式结尾）：
你上一次长时间专注于一件事，是什么时候？
如果你需要想一会儿才能想起来，也许答案已经在那个停顿里了。

推荐：方案 A，原因：与文章的批判基调和紧迫感一致，比总结式结尾有力量，又不显说教
```

### 示例 2：散文结尾

**输入：**
> 文章核心：写了在外地工作十年，某天在超市闻到一种熟悉的气味，突然想起了家乡
> 情感基调：淡淡的乡愁，平静中带一点惆怅
> 还没有结尾，不知道怎么写

**输出：**
```
【结尾设计方案】
文章核心：一种气味穿过十年时光，让人突然理解了"故乡"这两个字的重量
情感基调：平静的惆怅，不是撕心裂肺，是一种温柔的疼
结尾任务：完成情感落脚，不拔高，留余韵

方案 A（情感收束）：
我没有买那瓶酱。站了很久，然后去买了别的东西。
但那天回到出租屋，我第一次想：如果有一天回去，我想先去那条街走一走。就走走，不用做什么。

方案 B（场景定格）：
超市的广播在催促快要打烊了。我抱着购物篮走向收银台。
那瓶酱还放在货架上。我没带走它，但它已经带走了什么。

方案 C（回扣开头，需视开头内容调整）：
如果你的开头是某个"离家的那一天"的场景，可以在结尾回到那个场景，用"现在我才明白……"的句式完成闭环。

推荐：方案 B，原因：散文的力量在于克制，用"带走了什么"这样的留白比直接说"我想家了"更有余韵
```

## Best Practices

- 结尾方案要基于全文内容，不能和前文的情感基调割裂——结尾是文章最后一次呼吸，不是另起炉灶。
- 议论文结尾避免用"综上所述"；散文结尾避免直接说教；小说结尾避免过度解释。
- 如果当前结尾只是"太弱"而不是"完全错误"，可以在现有基础上强化，而不必推翻重写。

## Edge Cases

- **文章没有明确核心**：结尾前必须先追问"这篇文章最想让读者记住什么"，没有核心就没有收束点。
- **作者要求"有升华感"的结尾**：提醒作者升华要从文章内容中自然生长出来，强行拔高反而会让结尾显得空洞。
- **故事结局已经确定但结尾文字很弱**：聚焦在最后场景的细节和最后一句话的节奏，而非重新构思结局。
