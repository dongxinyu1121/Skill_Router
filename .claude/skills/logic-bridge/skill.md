# 论证缺口填补

本技能解决"有论据、有结论，但中间跳跃太大"的逻辑类卡壳。当读者看了论据还是不明白为什么能得出那个结论，说明论证链条中间缺少推导步骤。本技能帮助识别缺口，提供补充方向。

## Workflow

### 第一步：提取论据和结论

从已写内容中提取：
- **论据**：作者给出的事实、数据、案例
- **结论**：作者试图论证的观点
- **中间的推导**：已有的推导步骤（如果有）

### 第二步：测试论证链条

用"因此测试"检查每一步推导：

```
检查方式：
把论据和结论拼在一起读：
"[论据]，因此[结论]。"

如果这句话读起来有明显跳跃感，说明中间缺少推导步骤。
```

常见的跳跃类型：

| 跳跃类型 | 例子 | 缺少什么 |
|---------|------|---------|
| 个案到普遍 | 这个人成功了，因此努力就能成功 | 缺：为什么这个案例有代表性 |
| 相关到因果 | A和B同时出现，因此A导致B | 缺：为什么不是B导致A，或第三因素 |
| 部分到整体 | 这个部分有问题，因此整体都有问题 | 缺：这个部分是否代表整体 |
| 应然到实然 | 这是好的，因此人们会这样做 | 缺：什么机制让人们会选择好的 |
| 事实到价值 | 这件事发生了，因此是对的 | 缺：为什么发生的就是应该的 |

### 第三步：提供补充推导方向

识别缺口后，给出具体的补充步骤，每步包含：
- 需要回答的问题
- 建议的论证方式

### 第四步：输出结果

```
【论证缺口分析】
论据："[作者给出的论据]"
结论："[作者的结论]"
跳跃测试：[拼在一起读，说明跳跃感在哪里]
跳跃类型：[哪种类型的跳跃]

缺口 1：需要回答"[问题]"
　建议论证方式：[举例/数据/类比/权威引用]

缺口 2：需要回答"[问题]"（如有）
　建议论证方式：[举例/数据/类比/权威引用]

补充后的完整链条：
[论据] → [缺口1的内容] → [缺口2的内容] → [结论]
```

## Usage

提供具体的论据和你想得出的结论，以及已有的推导步骤（如果有）。

## Examples

### 示例 1：个案到普遍的跳跃

**输入：**
> 论据：引用了乔布斯辍学后创业成功的案例
> 结论：大学学历不是成功的必要条件

**输出：**
```
【论证缺口分析】
论据："乔布斯辍学后创业成功"
结论："大学学历不是成功的必要条件"
跳跃测试："乔布斯辍学后成功了，因此学历不是成功的必要条件。"——单个案例无法证明普遍规律，读者会质疑"那他只是特例呢"
跳跃类型：个案到普遍

缺口 1：需要回答"乔布斯只是特例，还是有大量类似情况"
　建议论证方式：数据——提供辍学或无学历成功者的统计数据，或其他知名案例列举

缺口 2：需要回答"学历和成功之间是什么关系"
　建议论证方式：分析——学历提供的是什么（知识/社交网络/信号），这些东西是否有替代途径

补充后的完整链条：
[乔布斯辍学成功] → [并非孤例，数据显示X%的科技创业者没有完成大学教育] → [学历提供的优势（知识、人脉、信号）可以通过其他途径获得] → [因此学历不是成功的必要条件]
```

### 示例 2：相关到因果的跳跃

**输入：**
> 论据：城市化率越高的地区，人均GDP越高
> 结论：城市化推动了经济发展

**输出：**
```
【论证缺口分析】
论据："城市化率高的地区，人均GDP也高"
结论："城市化推动了经济发展"
跳跃测试："城市化率和GDP正相关，因此城市化推动了经济发展。"——相关≠因果，可能是经济发展带动了城市化，或两者都受第三因素影响
跳跃类型：相关到因果

缺口 1：需要回答"是城市化导致GDP增长，还是GDP增长导致城市化"
　建议论证方式：时间顺序分析——哪个先发生？或引用控制变量研究

缺口 2：需要回答"排除其他可能的原因"
　建议论证方式：对比案例——找出城市化程度增加但经济没增长的案例，分析原因；或引用经济学研究说明机制

补充后的完整链条：
[城市化率与GDP正相关] → [控制其他变量后，城市化仍与经济增长正相关（引用研究）] → [城市化通过集聚效应降低交易成本、提高劳动力匹配效率（机制解释）] → [因此城市化推动了经济发展]
```

## Best Practices

- 不是所有跳跃都需要填补——对于共识性推论（"睡眠不足影响健康"不需要逐步论证），可以省略中间步骤。
- 补充推导不等于把文章写得越来越长，有时一句话就能填补缺口。
- 填补缺口后，建议作者用"因此测试"重新读一遍，确认链条是否已经流畅。

## Edge Cases

- **论据和结论之间有多个缺口**：逐个处理，优先填补最大的跳跃。
- **论据本身是错的或有争议的**：先指出论据的问题，不能在错误的基础上填补推导。
- **文章是散文而非议论文**：本技能主要适用于说理性写作，散文的"逻辑"是情感逻辑，不适用本技能的标准。
