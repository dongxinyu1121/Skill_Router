# 读者定位

本技能解决"不确定写给谁看，导致深浅拿捏不准"的读者类卡壳。读者不清晰，作者在每个词汇选择、每个概念是否需要解释上都会反复纠结。本技能帮助建立明确的读者画像，为后续写作提供决策标准。

## Workflow

### 第一步：从已写内容反推当前隐含读者

通过以下信号识别文章当前假设的读者：

| 信号 | 意味着 |
|------|--------|
| 专业术语大量出现且未解释 | 假设读者有专业背景 |
| 基础概念有详细解释 | 假设读者是入门级 |
| 类比举例非常通俗 | 假设读者是普通大众 |
| 叙述跳跃快，省略多 | 假设读者已有相关知识 |
| 情感诉求多于逻辑论证 | 假设读者是情感驱动的普通人 |

### 第二步：帮助作者明确目标读者

通过以下维度建立读者画像：

**基本维度：**
- 年龄段：什么阶段的人最可能读这篇文章
- 背景知识：对这个话题了解多少（完全不懂 / 有基础 / 有深度了解）
- 阅读目的：他们为什么会读这篇文章（学习 / 娱乐 / 解决问题 / 获得共鸣）

**写作决策维度：**
- 解释深度：什么程度的概念需要解释，什么可以直接用
- 语言风格：正式书面 / 轻松口语 / 专业但可读
- 论证方式：逻辑推理 / 数据说服 / 故事共鸣

### 第三步：建立写作决策标准

给出可以直接用于判断写作细节的标准：

```
"当我不确定某个概念要不要解释时，问自己：
  我的目标读者（[具体描述]）在读到这里之前，
  已经知道这件事了吗？
  如果是，跳过；如果否，用一句话解释。"
```

### 第四步：输出结果

```
【读者定位分析】
从已写内容判断的当前隐含读者：[描述]
与实际目标读者的差异：[如有差异，说明在哪里]

目标读者画像：
　背景知识：[对这个话题的了解程度]
　阅读目的：[他们读这篇文章想得到什么]
　一句话描述："[理想读者是谁]"

写作决策标准：
　专业术语：[哪些需要解释，哪些可以直接用]
　概念深度：[展开到什么程度就够了]
　语言风格：[偏正式/偏口语，用词倾向]
　论证方式：[逻辑/数据/故事，哪种最有效]

对已写内容的影响：[已有内容有哪些地方需要根据读者定位调整]
```

## Usage

提供已写内容，以及你希望这篇文章发布在哪里（平台/场合），或者最理想的读者是谁（如果能描述）。

## Examples

### 示例 1：读者混乱

**输入：**
> 文章主题：介绍人工智能在医疗中的应用
> 困惑：不知道该写多深，有时候解释得很细，有时候又跳得很快

**输出：**
```
【读者定位分析】
从已写内容判断的当前隐含读者：混合——部分假设读者懂AI（有"神经网络""训练数据"等术语未解释），部分又在解释非常基础的概念（"AI就是让计算机模拟人类思维"）
与实际目标读者的差异：写作时在"专业人士"和"普通大众"之间反复切换，没有统一标准

目标读者画像（建议）：
　背景知识：对AI有耳闻但没有技术背景；对医疗有基础了解（知道诊断、影像检查等概念）
　阅读目的：了解AI在医疗领域能做什么，以及这对普通人意味着什么
　一句话描述："受过良好教育但没有AI或医学专业背景的成年读者"

写作决策标准：
　专业术语：AI技术术语（如神经网络、深度学习）一律用类比解释，不假设读者懂；医疗常识（如X光、CT扫描）可以直接用，不需要解释
　概念深度：说清楚"AI能做什么"和"效果怎么样"即可，不需要解释"AI怎么做到的"
　语言风格：偏科普，流畅可读，不学术不口水
　论证方式：案例+数据，避免纯技术描述

对已写内容的影响：
　需要调整：所有未解释的AI术语，用括号或类比方式补充解释
　需要删除：过于技术性的实现细节，普通读者不需要也不感兴趣
```

### 示例 2：受众太宽泛

**输入：**
> 文章主题：亲子沟通技巧
> 计划发布平台：微信公众号
> 困惑：不知道是写给家长的还是写给孩子的，两边都想兼顾

**输出：**
```
【读者定位分析】
从已写内容判断的当前隐含读者：偏向家长（使用了"孩子""引导"等视角明确为家长的词）
与实际目标读者的差异：作者想同时写给家长和孩子，但两个群体需要完全不同的内容和语气

目标读者画像（建议）：
　确定一个主要读者：家长（公众号的主要读者群）
　背景知识：有一定育儿意识，但在亲子沟通上遇到了困难
　阅读目的：获得可以立刻用的具体方法，改善与孩子的沟通
　一句话描述："在亲子沟通上遇到挑战、主动寻求方法的家长"

写作决策标准：
　视角：全程家长视角，"孩子"是"你的孩子"而不是读者自己
　语言风格：温暖、有共情，但要有实操性，不要只有道理
　论证方式：场景化举例（"当孩子说……的时候，你可以……"），让家长立刻代入
　深度：不需要解释心理学原理，直接给场景和方法

对已写内容的影响：无需大改，但要统一视角——确保全文都在对家长说话，不要突然切换成对孩子说话
```

## Best Practices

- 读者定位越具体越好，"所有人"等于没有定位。"25-40岁、有孩子、受过高等教育的城市女性"比"家长"更有用。
- 读者定位确定后，用"决策标准"的形式呈现，让作者在写每个细节时有可以操作的判断依据。
- 同一篇文章不应该试图同时服务多个背景差异很大的读者群；如果必须，建议分开写多篇。

## Edge Cases

- **纯个人日记**：没有外部读者，读者定位不适用；如果打算公开，再来做定位。
- **命题作文有明确阅卷对象**：读者就是阅卷老师，按照题目要求写作即可，不需要另做定位。
- **作者坚持想写给所有人**：解释为什么这样做会导致写作困难，然后帮助找到一个"最典型的读者"作为主要对象，其他人是附带受益。
