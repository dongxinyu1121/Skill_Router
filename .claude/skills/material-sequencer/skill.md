# 素材排序

本技能解决"资料收集得很多，但不知道怎么放进文章、按什么顺序排列"的整合类卡壳。通过分析素材的性质和文章的逻辑需求，提供具体的排序和组织方案。

## Workflow

### 第一步：对素材进行分类

将所有素材归入以下类别：

| 类别 | 说明 | 在文章中的作用 |
|------|------|-------------|
| 背景素材 | 解释语境、历史、现状 | 通常在开头或论点引入前 |
| 核心论据 | 直接支撑主要论点的数据、研究 | 最靠近论点，越重要越靠前 |
| 案例素材 | 具体事例，使论点可感 | 紧跟论点之后，用来具体化 |
| 对比素材 | 反面案例或对照数据 | 用于强化差异或处理反驳 |
| 支撑素材 | 补充说明，非核心但有价值 | 在主要论证后，作为辅助 |
| 结论素材 | 引导向结论的论据或引用 | 靠近文章后半段 |

### 第二步：确定排序原则

根据文章类型，选择排序原则：

| 文章类型 | 排序原则 |
|---------|---------|
| 议论文 | 重要性排序：最强论据最先出场（先发制人），或最后出场（留下最深印象）；背景在最前，对比/反驳在主要论证后 |
| 说明文 | 逻辑排序：从整体到局部，从简单到复杂，从已知到未知 |
| 叙事类 | 时间顺序或情感递进：按事件发展或情绪变化排列 |
| 分析类 | 因果排序：原因→结果，或结果→原因（倒推式） |

### 第三步：提供具体排序方案

给出素材的具体排列顺序，每条说明：
- 这条素材的类别
- 放在哪个位置
- 和前后素材的逻辑连接

### 第四步：输出结果

```
【素材排序方案】
文章类型：[判断]
核心论点：[确认]
排序原则：[选用的原则]

素材分类结果：
　背景素材：[列出]
　核心论据：[列出，按重要性排序]
　案例素材：[列出]
　对比素材：[列出]
　支撑素材：[列出]

推荐排序：
1. [素材名/简述] — 类别：[X] — 作用：[在文章中起什么作用]
2. [素材名/简述] — 类别：[X] — 作用：[...]
...N. [素材名/简述]

过渡建议：[相邻素材之间如何自然连接]
不建议使用：[哪些素材相关性低，建议移除]
```

## Usage

列出你收集的所有素材（简短描述即可），并说明文章的核心论点和类型。

## Examples

### 示例 1：议论文素材排序

**输入：**
> 文章论点：减少工作时间不会降低生产力，反而可能提升
> 素材：
> A. 冰岛2015-2019年的4天工作制实验，生产力持平或提升
> B. 微软日本2019年4天工作制，生产力提升40%
> C. 历史上工作时间从12小时缩短到8小时的过程
> D. 研究：工作超过50小时后，每小时边际生产力显著下降
> E. 反对意见：服务行业难以实施4天工作制
> F. 一位经理的证词：他的团队改为4天工作后，效率反而提高了

**输出：**
```
【素材排序方案】
文章类型：议论文
核心论点：减少工作时间不降低生产力，可能提升
排序原则：最强论据先出场（建立可信度）+ 反驳放在主论证后

素材分类结果：
　背景素材：C（工作时间历史变化）
　核心论据：B（微软数据40%，最有冲击力）、A（冰岛实验，规模大，可信度高）
　科学支撑：D（研究数据，解释为什么长时间工作效率反而低）
　案例素材：F（个人证词，使数据有人性温度）
　对比素材：E（反对意见）

推荐排序：
1. D（科学支撑）— 类别：核心论据 — 作用：用研究数据解释为什么长时间工作效率更低，先建立理论基础
2. B（微软日本）— 类别：核心论据 — 作用：用最有冲击力的数字（40%）建立论点的说服力高峰
3. A（冰岛实验）— 类别：核心论据 — 作用：补充更大规模的实验数据，证明B不是孤例
4. F（经理证词）— 类别：案例素材 — 作用：让数据变得可感，读者能代入
5. E（反对意见）— 类别：对比素材 — 作用：主动处理反驳，显示论证的客观性，然后回应
6. C（历史背景）— 如使用，放开头引入，而非放在论证中

过渡建议：
- D→B：用"这正是微软日本……验证了这一点"自然连接
- A→F：用"这不只是企业实验室的发现，在实际工作中……"过渡到个人案例

不建议使用：C（历史背景较长且和核心论点关联不强，使用后文章会显得头重；如果引言已经有背景，可以删去）
```

### 示例 2：说明文素材排序

**输入：**
> 文章：解释"深度工作"是什么
> 素材：
> A. 深度工作的定义（卡尔·纽波特的概念）
> B. 浅工作的定义
> C. 一个作家如何实践深度工作的具体例子
> D. 为什么现代职场越来越难实现深度工作（手机、开放办公室等）
> E. 深度工作能带来什么好处
> F. 如何建立深度工作的习惯（具体步骤）

**输出：**
```
【素材排序方案】
文章类型：说明文
核心目的：让读者理解"深度工作"是什么，以及为什么和如何实践
排序原则：从已知到未知，从"是什么"到"为什么"到"怎么做"

素材分类：
　背景素材：B（浅工作，通过对比引入）
　定义层：A（核心概念）
　原因层：D（为什么重要/稀缺）
　价值层：E（好处）
　案例层：C（具体例子）
　操作层：F（如何实践）

推荐排序：
1. B（浅工作） — 类别：背景/对比 — 作用：从读者已知的（忙碌、碎片化工作）切入，用对比引出深度工作的概念
2. A（深度工作定义） — 类别：核心概念 — 作用：正式定义，让读者知道"说的是什么"
3. D（为什么稀缺） — 类别：原因分析 — 作用：解释为什么这个概念重要，建立读者的重视感
4. E（好处） — 类别：价值说明 — 作用：回答"为什么我应该在意这件事"
5. C（作家案例） — 类别：案例 — 作用：让抽象概念变得可见，读者知道"具体是什么样的"
6. F（如何实践） — 类别：操作指南 — 作用：给读者可以行动的出口，是文章最实用的部分

过渡建议：
- B→A：用"与之相对的，就是深度工作……"直接对比过渡
- E→C：用"让我们看一个真实的例子……"引入案例
- C→F：用"那么，我们怎么做到这一点？"过渡到操作层
```

## Best Practices

- 排序之前必须先明确核心论点，素材的顺序服务于论点，不是素材决定论点。
- 议论文中，最强的论据通常放第二位（第一位建立语境，第二位是第一个高潮）或最后一位（留给读者最深印象）。
- 不要试图用上所有素材——过度堆砌会让文章失去焦点，宁可留下，不要硬塞。

## Edge Cases

- **素材之间有矛盾**：先用 `contradiction-resolver` 处理矛盾，再排序。
- **素材太少，不够支撑论点**：本技能无法解决素材不足，建议使用 `detail-generator` 或 `knowledge-gap-detector` 补充素材。
- **作者有特定的叙事顺序偏好**：在作者偏好的框架内做排序建议，而不是推翻作者的整体构想。
