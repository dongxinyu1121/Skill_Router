# 对话自然化

本技能解决小说、剧本中"对话读起来像台词朗诵，不像真人说话"的卡壳。通过分析对话的具体问题，帮助作者写出有个性、有生活气息的真实对话。

## Workflow

### 第一步：诊断对话的问题类型

| 问题类型 | 表现 |
|---------|------|
| 过于正式 | 对话像书面语，用词比日常说话文绉绉 |
| 信息传递式 | 对话只是为了告知读者信息，人物说话像在开会汇报 |
| 每人说话风格相同 | 不同人物说话方式一样，换掉名字也分不清是谁 |
| 没有潜台词 | 人物把什么都说出来了，缺乏弦外之音 |
| 回应太直接 | A问B，B直接回答，没有真实对话中的绕弯、回避、误解 |
| 节奏太整齐 | 每句话差不多一样长，读起来像乒乓球 |

### 第二步：分析人物说话风格

好的对话中，每个人物应该有自己的说话方式：
- **词汇选择**：这个人会用文绉绉的词还是大白话？
- **句子长度**：爱说长句子还是短句子？
- **说话习惯**：爱反问？爱用口头禅？说话喜欢绕弯子还是直接？
- **信息披露方式**：这个人在这段对话中愿意透露多少？

### 第三步：提供修改建议和示例

针对具体问题，给出修改建议并演示改写：

### 第四步：输出结果

```
【对话自然化分析】
诊断出的问题：[主要问题类型，1-2个]

人物说话风格分析：
　[人物A]：[说话特征]
　[人物B]：[说话特征]

修改原则：[针对这段对话最重要的2-3条修改原则]

改写示例：
原对话：
"[原版对话]"

改写后：
"[改写版对话]"

改写说明：[改了什么，为什么这样改]
```

## Usage

提供需要改善的对话段落，以及对话中涉及的人物简介（性格、关系、当时的情绪状态）。

## Examples

### 示例 1：信息传递式对话

**输入：**
> 人物：父亲（强势，不善表达情感）和女儿（渴望认可）
> 原对话：
> 父亲："你知道你今年的成绩不够理想，你需要更加努力才能达到你的目标。"
> 女儿："我知道，我会努力的。"
> 父亲："好的，我期待你下次有更好的表现。"

**输出：**
```
【对话自然化分析】
诊断出的问题：
1. 信息传递式——对话在传达"父亲对成绩不满意"这个信息，但完全没有情感和关系的呈现
2. 过于正式——父亲说话像在做评估报告，女儿回应像在汇报工作

人物说话风格分析：
　父亲：强势、不善表达情感，说话可能简短直接，用命令口气而非商量；他在意成绩但可能不知道怎么说关心
　女儿：渴望认可，可能会在父亲面前压抑真实感受，给出"符合期待"的回应

修改原则：
1. 让父亲的"强势"通过说话方式而非内容表现（他不说"我期待你更好"，他可能只是沉默，或者转移话题）
2. 给女儿一点真实的情绪——她不会只说"我知道，我会努力的"，她心里有话
3. 加入潜台词——父女之间没说出口的东西比说出来的更重要

改写后：
父亲（不看她，翻着桌上的纸）："数学差了十分。"
女儿（停顿）："嗯。"
父亲："下次补上。"
女儿："……你就没有别的话想说？"
父亲终于抬头，看了她一眼，又看回去："好好吃饭。"

改写说明：
- 父亲用"差了十分"替代评估式总结——更像真实说话方式，也更扎心
- "下次补上"是父亲的"期望"，但以命令形式表达，符合强势性格
- 女儿的"你就没有别的话想说"是潜台词外化——她想要的不是关于成绩的评价，而是别的什么
- 父亲"好好吃饭"是一个逃避，但也是一种在意——他不知道怎么说，就说了这个
```

### 示例 2：每人风格相同

**输入：**
> 两个朋友在争论要不要向老板提加薪
> 原对话：
> 甲："我认为你应该去找老板谈加薪，因为你的工作表现很好，你值得更高的薪水。"
> 乙："但是我担心老板会不高兴，我不想破坏我们的关系。"
> 甲："你不应该这样想，你有权利争取你应得的。"

**输出：**
```
【对话自然化分析】
诊断出的问题：
1. 每人风格相同——甲和乙说话结构完全一样（"我认为…因为…""但是我…我不…"），换名字也分不清
2. 回应太直接——甲说一个观点，乙直接反对，然后甲直接反反对，像辩论赛

修改原则：
1. 给甲一个更"积极进取"的说话方式（他可能用的是口语，爱反问，说话短促）
2. 给乙一个更"谨慎顾虑多"的说话方式（他可能绕弯子，说话长，总有"但是"）
3. 让真实对话的"绕"出来——真实生活中朋友聊这种话题，不会这么正面交锋

改写后：
甲："你知道旁边组的小李吗？年底要求加薪了。"
乙："他跟老板关系好。"
甲："你跟老板关系不好？"
乙："不是不好，就是……你懂的，他那个人，说不定就……"（摆摆手）
甲："说不定怎样？他还能把你开了？"
乙："不是，就是——算了，我再想想。"
甲（叹气）："你再想想，想到退休算了。"

改写说明：
- 甲用"你知道小李吗"侧面切入，不直接说"你应该去谈"——更像朋友说话方式
- 乙的犹豫通过"省略号""摆手""算了"等行为表现出来，不需要说全
- 两人的性格差异通过节奏差异体现（甲短促直接，乙长句绕弯）
```

## Best Practices

- 好的对话"少说"——真实的人在对话中不会把所有意思都说全，省略、绕弯、打断才是真实对话的质感。
- 每个人物的说话方式要和他的性格、教育背景、当下情绪一致。
- 不要让对话承担太多情节解释功能——"如你所知，五年前我们分开了"这种信息传递式对话读者会出戏。

## Edge Cases

- **剧本格式的对话**：同样适用，但格式上保留舞台指令。
- **历史或古风设定**：说话方式要符合时代，但"真实感"的原则不变——即使是古代人，也不应该说话像在背台词。
- **外语翻译腔**：如果对话读起来像翻译过来的，建议重读大声念出来，找到别扭的地方再改。
