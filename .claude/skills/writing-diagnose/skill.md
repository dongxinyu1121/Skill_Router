# 写作卡壳诊断

本技能是 writing-unstuck 系统的统一入口。当作者说"写不下去了"，本技能通过阅读已写内容和作者描述，快速定位卡壳的真正原因，并推荐最合适的专项技能。

## Workflow

### 第一步：读取已写内容

阅读作者提供的全部已写内容，建立对以下维度的基本判断：

- **文章类型**：议论文 / 小说 / 散文 / 报告 / 其他
- **当前进展**：文章写到哪个阶段（开头 / 中段 / 接近结尾）
- **整体风格**：语气、用词倾向、叙述方式

### 第二步：理解作者的卡壳描述

提取作者用自己的话描述的卡壳症状，结合已写内容进行交叉判断。若作者没有额外描述，则仅凭内容进行诊断。

### 第三步：对照类型表诊断

| 卡壳类型 | 典型症状 | 推荐技能 |
|---------|---------|---------|
| 结构类 | 不知道下一段写什么，大纲断了 | `outline-expander` / `argument-builder` / `plot-unstuck` |
| 素材类 | 细节不够，举不出例子，两段衔接不上 | `detail-generator` / `angle-finder` / `transition-writer` |
| 风格类 | 感觉语气变了，读起来像换了个人在写 | `tone-matcher` / `voice-amplifier` |
| 结尾类 | 内容差不多了但不知道怎么收 | `ending-designer` |
| 方向类 | 忘了自己要写什么，跑题了，不知道在哪停 | `theme-retriever` / `purpose-clarifier` / `focus-restorer` |
| 逻辑类 | 前后矛盾，论据跳跃，因果关系理不清 | `contradiction-resolver` / `logic-bridge` / `causal-clarifier` |
| 情绪类 | 没兴趣继续写，反复改同一段，觉得写得很烂 | `motivation-reigniter` / `perfectionism-break` / `quality-assessor` |
| 节奏类 | 某部分展开太细后面不知怎么收，整体比例失衡 | `pacing-checker` / `proportion-balancer` |
| 读者类 | 不确定写给谁看，深浅拿捏不准 | `audience-definer` |
| 信息取舍类 | 素材太多不知道选哪些，某个点自己不够了解 | `overload-filter` / `knowledge-gap-detector` |
| 人物角色类 | 角色行为不合理，对话读起来不自然 | `character-unstuck` / `dialogue-naturalizer` |
| 创意类 | 想法平庸找不到新鲜切入，脑子空白 | `cliche-breaker` / `blank-mind-starter` |
| 语言类 | 用词反复重复，句式太单调 | `word-variety-expander` / `sentence-diversifier` |
| 开头类 | 新段落不知道怎么切入，引子没吸引力 | `section-opener` / `hook-strengthener` |
| 整合类 | 多个话题不知道怎么拼，资料不知道怎么排序 | `multi-thread-organizer` / `material-sequencer` |

### 第四步：输出诊断结果

以固定格式输出，作者可据此直接调用推荐技能：

```
【卡壳诊断结果】
卡壳类型：[类型名称]
症状描述：[一句话说明具体卡在哪里]
推荐技能：[技能名称]
判断依据：[2-3句，说明为什么判断是这种卡壳]
追问：[如果信息不足以准确判断，提出最关键的一个问题；信息充足则填"无"]
```

## Usage

将已写内容全部粘贴，并用一句话描述自己卡在哪里。本技能自动完成诊断，输出结果可直接指导后续使用哪个专项技能。

**输入格式：**
```
【已写内容】
（粘贴文章）

【卡壳描述】
（用一句话说明写不下去的感受）
```

## Examples

### 示例 1：结构类卡壳

**输入：**
> 【已写内容】
> 人工智能正在改变医疗行业。首先，AI 辅助诊断系统已在多家医院部署……（展开了三段关于诊断的内容）
>
> 【卡壳描述】
> 诊断这块写完了，但不知道下面该写什么了

**输出：**
```
【卡壳诊断结果】
卡壳类型：结构类
症状描述：当前议题（AI辅助诊断）已写完，不知道文章接下来该展开哪个方向
推荐技能：outline-expander
判断依据：已写内容结构清晰，卡壳位置在段落之间，属于大纲推进问题而非素材或表达问题
追问：无
```

### 示例 2：情绪类卡壳

**输入：**
> 【已写内容】
> （三段内容，但每段都有多处划掉重写的痕迹）
>
> 【卡壳描述】
> 我总是觉得写出来的不够好，改了很多遍，现在根本不敢往下写了

**输出：**
```
【卡壳诊断结果】
卡壳类型：情绪类（完美主义）
症状描述：反复修改同一段落，因为害怕写得不好而无法向前推进
推荐技能：perfectionism-break
判断依据：卡壳原因不在内容或结构，而在于作者对"写好"的过度执念导致行动瘫痪
追问：无
```

### 示例 3：信息不足，需要追问

**输入：**
> 【已写内容】
> （500字的散文片段）
>
> 【卡壳描述】
> 写不下去了

**输出：**
```
【卡壳诊断结果】
卡壳类型：待定
症状描述：描述过于模糊，无法仅凭已写内容确定卡壳原因
推荐技能：待定
判断依据：已写内容本身完整流畅，卡壳原因不在文字质量上
追问：你现在最大的感受是什么？（A）不知道接下来写什么内容；（B）知道写什么但不知道怎么写；（C）提不起兴趣继续写；（D）觉得写得不够好
```

## Best Practices

- 优先相信作者的自我描述，但要用已写内容交叉验证。作者说"找不到细节"，但内容本身逻辑断裂，则应诊断为结构类而非素材类。
- 情绪类卡壳往往被作者误描述为内容问题，识别关键词：反复修改、不敢往下写、感觉很烂、没动力等。
- 同一篇文章可能同时存在多种卡壳，优先诊断最根本的一种，在"判断依据"中提及其他可能。

## Edge Cases

- **作者什么都没提供**：要求作者至少提供卡壳描述，内容可以只粘贴最后一段。
- **文章太长**：只需阅读最后 1/3 的内容，配合卡壳描述进行诊断。
- **多种症状并存**：选择最影响写作推进的那种作为主诊断，其余在"判断依据"中注明。
